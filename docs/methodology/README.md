## 回答"历史方法能不能合并"

能，而且历史已经在做：

| 合并方式 | 实例 | 结果 |
|---|---|---|
| 不同数据族的腿拼装 | fnd6 三锚 + cash45/cfoev45 引擎 + PV 腿 + 分析师评级腿（7 腿） | SF 5.30 / testS 2.26 |
| fnd2 双锚（回购 − 无形资产）+ 引擎腿 | w94_e | SF 5.89 |
| 引擎腿 + 冷门锚 + 量能腿 + 价量腿 | 骨架 A 家族 | SF 6.19 |

**合并的有效前提**（都是实证）：
1. 引擎腿（`cash45` / `cfoev45`）不能丢 —— 它们是质量来源
2. PV 腿不能丢 —— 它是验证期稳定性来源
3. 新轴（分析师、新闻、期权）**只能叠加**，不能替换上面两类
4. 锚腿要**冷门**（alphaCount 低）—— 这是过相关性墙的唯一抓手
