## 1. 原帖写的是什么

**机制**：收益率极端偏离市场平均的股票，会因投资者心理偏差被过度反应。
- 极端低收益 → 恐慌抛售（"草木皆兵"）→ 未来补涨 → **做多**
- 极端高收益 → 过度买入（"守株待兔"）→ 未来回落 → **做空**
- 中间区间 → 不操作（`is_nan(0)`）

**原帖代码（OCR）**：

```
# 第 1 版（未中性化）：S 2.22 / F 0.96 / TO 69.29%
a = rank(returns);
b = rank(-returns);
a < 0.2 ? b : a > 0.8 ? -a : is_nan(0)

# 第 2 版（rank(cap) 中性化，作者称已成功提交）：S 2.29 / F 1.01 / TO 68.92%
a = rank(returns);
b = rank(-returns);
a < 0.2 ? group_neutralize(b, rank(cap))
        : a > 0.8 ? group_neutralize(-a, rank(cap))
        : is_nan(0)
```

**原帖设置**：GLB / TOP3000 / delay 1 / decay 6 / Neutralization=Subindustry / truncation 0.08 / Pasteurization On

## 2. 复现遇到的第一个硬事实

**GLB 现在没有 `returns` 字段。** 2026-11-16 实测 GLB pv1 只有 9 个字段：
`adjfactor / adv20 / cap / close / country / currency / cusip / dividend / exchange`。

原帖写于 2023 年，平台字段已变。**必须变体**：

```
r = close / ts_delay(close, 1) - 1        # 用 close 派生日收益
```

第二个硬事实：**`group_neutralize(x, rank(cap))` 现在会被平台拒绝**：

```
Incompatible unit for input of "group_neutralize" at index 1,
expected "Unit[Group:1]", found "Unit[]"
```

`rank(cap)` 是连续值，不是分组。必须用 `bucket` 转成组：

```
group_neutralize(b, bucket(rank(cap), range="0,1,0.1"))
```

## 4. 从数据里得到的四条结论

1. **复现路线成立**。原帖写 2023 年的 GLB 反转因子，用今天的字段（close 派生）仍然拿到 **S 1.82**，方向、阈值、结构都对。
2. **cap 中性化有效**：S 1.82 → 1.96（+0.14），F 0.84 → 0.92。但实现方式必须从 `rank(cap)` 改成 `bucket(rank(cap))`。
3. **decay 有最优档**：decay 6→8 时 F 0.92→0.93；**decay 10 反而掉到 0.91**，decay 20 掉到 0.72。压换手的边际收益在 decay 8 附近耗尽。
4. **GLB 的 EMEA 是硬门槛**：0.17~0.32，全变体都没救过来。AMER 可以用 cap 分组顶到 1.00，EMEA 不行。

1. **收紧分位**（0.2/0.8 → 0.15/0.85 或 0.1/0.9）：只做最极端尾部，可能同时提 S 与 EMEA。已在跑但被并发抢占。
