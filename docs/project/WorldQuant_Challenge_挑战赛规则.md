# WorldQuant Challenge 挑战赛规则

> 来源：WorldQuant BRAIN 官方挑战赛说明。

---

## 一、概述

**WorldQuant Challenge** 是一项**永久的在线个人比赛**。用户通过提交 Alpha 策略来提高得分和排名。

- **新用户自动参加**挑战赛。
- 排行榜按**国家、大学和/或城市**对所有合格用户进行排名。
- 达到特定分数门槛后，可获得**研究顾问（Research Consultant）邀请资格**及专属培训课程。

---

## 二、级别与门槛

| 级别 | 分数门槛 | 权益 |
|---|---|---|
| 青铜 | > 1,000 分 | 入门级 |
| 白银 | > 5,000 分 | 可访问特别培训课程和视频 |
| 黄金 | > 10,000 分 | **有资格获得研究顾问（Research Consultant）邀请** |

> 获得 10,000 分仅获得**邀请资格**，最终能否成为顾问还需符合其他条件（例如是否为 BRAIN 顾问计划所运行国家的居民等）。
> 达到金牌/银牌级别的用户可通过 **Events 页面**访问特别培训课程和视频。

---

## 三、评分标准

### 3.1 概要

- 得分基于你提交的 Alpha 策略的**数量和质量**（以 5 年样本内表现为依据）。
- 得分也受**其他用户当天提交的 Alpha** 数量和质量影响。
- 得分按**每天（东部标准时间）**计算，而不是按每个 Alpha 计算。
- **每日最高得分：2,000 分**。通常每天提交 1–2 个 Alpha 即可接近上限。
- **没有负分**，得分不会降低。
- 得分每天在美国东部标准时间 **凌晨 3 点**更新。
- 得分相同的参与者**排名相同**。

### 3.2 详情

每天所有用户提交的 Alpha 会累积，并根据两个因素计算：

#### 数量因素（Quantity Factor）

- 一天内提交的 Alpha 数量越多，该因素越大，得分越高。

#### 质量因素（Quality Factor）

- 一天内提交的所有 Alpha 的**质量因素平均值**。
- 质量因素越大，得分越高，取决于以下设置和样本内结果：
  - **股票池（Universe）**：股票池越小，得分越高。
  - **自相关性（Self Correlation）**：越小越好。
  - **Fitness**：越高越好。
  - **延迟（Delay）**：**Delay-1（D1）Alpha 对得分的贡献大于 Delay-0（D0）Alpha**。

#### 归一化与最终得分

- 数量因素和质量因素会在**当天至少提交了一个 Alpha 的所有用户中**进行归一化处理。
- 最终每日得分 = 归一化后的数量因素 + 质量因素的函数。
- 每日得分上限为 **2,000 分**。

## 四、考试速查卡

| 要点 | 内容 |
|---|---|
| 比赛性质 | 永久在线个人赛 |
| 参与方式 | 新用户自动参加 |
| 排名维度 | 国家 / 大学 / 城市 |
| 青铜 | > 1,000 分 |
| 白银 | > 5,000 分 |
| 黄金 | > 10,000 分（顾问邀请资格） |
| 每日最高得分 | 2,000 分 |
| 更新时间 | 美东时间凌晨 3 点 |
| 数量因素 | 当天提交 Alpha 越多，得分越高 |
| 质量因素 | Universe 越小、自相关越低、Fitness 越高、D1 优于 D0，得分越高 |
| 是否有负分 | 否 |

---

## 五、常见考点

1. **多少分可以获得研究顾问邀请？** → **10,000 分（金牌）**，但需满足其他条件。
2. **每日最高多少分？** → **2,000 分**。
3. **得分几点更新？** → 美东时间 **凌晨 3 点**。
4. **D0 和 D1 哪个对得分贡献更大？** → **D1 > D0**。
5. **股票池大小对得分的影响？** → **股票池越小，得分越高**。
6. **挑战赛是否按每个 Alpha 计分？** → 否，按**每天**计分。
