# 笔试 vs 面试：同一份考纲，两种考法

> 依据：WQ BRAIN CHINA 置顶帖《BRAIN 研究能力笔试与面试学习指南》（原文已归档：`docs/exam/研究能力笔试面试学习指南.md`）
> 整理：2026-09-16 ｜ 归档整理：阿衡

---

## 一、结论：范围一样，考法不一样

**是的，知识范围可以认为是同一套——但"范围一样"不等于"同一张卷子"。**

原文三处措辞就是证据：

| 原文 | 说明 |
|---|---|
| 「**测试与面试涵盖以下几个大方向**」 | 明确写了两场共用这一份清单，范围是同一个 |
| 「涵盖以下几个**大方向**」 | 是**范围**词，不是**题型**词——它划定"考什么"，没说"怎么考" |
| 「建议重点理解概念，**能用自己的话解释，而非死记答案**」 | 这句对笔试是"防背题"的提醒，对面试是**核心评分项**——面试本来就只能"用自己的话讲" |

**所以准确的说法是：**

- ✅ **准备的材料可以共用一套**（这份考纲 + 官方文档 + 零基础四课）
- ❌ **准备的方式必须分两套**——笔试练"识别与复述"，面试练"开口讲、接追问"

而且面试一定会考到**这份考纲里没写**的东西，见第三节。

## 二、同一个知识点，两场考法差在哪

笔试是**客观题环境**：选项摆在眼前，你只要认得出。
面试是**口头追问环境**：没有选项，讲完还要接下一句"为什么"。

| 考点 | 笔试大概这样考（识别 / 复述） | 面试大概这样问（解释 / 追问） |
|---|---|---|
| Alpha 是什么 | 选出 Alpha 的正确定义 | 「用你自己的话说，Alpha 跟一个交易策略有什么区别？」 |
| 平台运行原理 | 选出回测流程的正确顺序 | 「中性化之后为什么权重和是 0？不中性化会怎样？」 |
| Simulation Settings | 选出 Decay / Truncation 的作用 | 「Truncation 设 0.08 是什么意思？你会在什么情况下调大/调小？」 |
| Sharpe | 给公式或选阈值 | 「为什么要乘 √252？」「Delay-1 要 1.25、Delay-0 要 2.0，为什么 Delay-0 门槛更高？」 |
| Turnover | 选出换手率的定义 | 「给你一个换手 60% 的 Alpha，你会怎么降？降了会伤到什么？」 |
| Fitness | 选出公式 | 「为什么公式里要有 max(Turnover, 0.125) 这个下限？直接除 Turnover 会出什么问题？」 |
| 中性化 | 选出中性化的作用 | 「`group_neutralize(x, g)` 和面板上 Neutralization 设成一样，什么时候等价、什么时候不等价？」 |
| 数据字段三类 | 选出向量字段要怎么处理 | 「拿到一个向量字段，你怎么判断该用 vec_avg 还是 vec_sum？选错会怎样？」 |
| 提交测试 | 选出哪些属于提交测试 | 「Sub-universe 没过，你会怎么改？为什么会有这条测试？」 |
| IS / OS / TEST | 选出各阶段时间范围 | 「为什么必须有 OS？只看 IS 的曲线会踩什么坑？」 |

**规律**：笔试停在**"是什么"**，面试从**"为什么"**开始，而且会一直追到**"你会怎么做"**。

## 三、考纲里没写、但面试几乎必问的四块

这是最容易被忽略的部分——照着考纲背完，面试照样会被问懵。

### 1. 你自己的 Alpha（杀伤力最大，也最难造假）

面试官不需要考你定义，他要判断你**是不是真的干过**：

- 你提交过什么 Alpha？思路从哪来的？
- 讲一个你最满意的——为什么有效？经济逻辑是什么？
- 讲一个卡住的——你怎么定位问题、怎么改的？
- 你的 Alpha 之间相关性怎么控制？

> **这块是你的强项，不是短板**：36 个已提交、48 轮实测、SUBMITTED_LEDGER 台账、相关性墙的实战经验——这些东西笔试一点用不上，面试却是硬通货。**前提是你能把它讲成一条完整的因果链**，而不是"我跑了 36 个"。

### 2. 追问到底的「为什么」

笔试选对就结束。面试会一层层剥：

- 「为什么中性化后多空两边正好抵消？」→ 追问「那市场中性到底中性掉了什么？还剩什么风险？」
- 「为什么要有 OS？」→ 追问「过拟合长什么样？你怎么判断一个 Alpha 是过拟合还是真有效？」

### 3. 动机与投入（行为面）

- 为什么想做研究顾问？
- 每周能投入多少小时？怎么跟主业平衡？
- 遇到连续两个月不出成果怎么办？

### 4. 临场构造

- 「如果想表达『近期成交量异常放大』这个思路，你会怎么写？」
- 「给这个表达式加个中性化，你会加在哪一层？为什么？」

## 五、缺口不在材料，在「开口」

材料 14/14 齐了，但**能背 ≠ 能讲**。真正的缺口是这三件事：

1. **没有把自己的实战串成故事**：36 个提交、相关性墙、48 轮实测，目前散在台账和日志里，还没整理成一段能讲 3 分钟的东西。
2. **没练过被追问**：看材料是输入，面试是输出 + 接招。
3. **数值记不牢**：面试官随口问「Delay-1 的 Sharpe 门槛是多少」，答不上来很伤。

## 六、下一步：按面试方式练

建议顺序：

1. **先把「自己的 Alpha」这段故事写出来**（面试独有无替代，且是你的优势区）
2. **再做对练**：我按考纲逐点发问，你口述回答，我按面试标准挑漏洞、追「为什么」
3. **最后过数值**：把阈值/公式单独抽一张速查卡，考前扫一遍

> 模拟题不练（按约定）。对练从哪个板块开始，你定。
