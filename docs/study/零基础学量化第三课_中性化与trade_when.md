## TL;DR 考试速查卡

- 达 **10,000 分**后约 **2–3 天**收 workday 问卷邀请（当天不算）；未收到原因=地区非运营 / 账户异常行为（如每天秒回测"可提交"Alpha）。
- 交 **15+ 个 Alpha** 可加速问卷审核；背调约 **1 个月**（春节更长）；合同回传即开通顾问权限。
- **trade_when(开仓条件, 平仓条件, alpha 值)**：三参数。平仓条件成立→直接平仓不交易；否则看开仓条件，成立则更新 alpha 值，不成立则**继承上期 alpha 值** → 显著降低 turnover。
- **中性化 = 多空中性化（long-short）**：一半的钱做多、一半的钱做空（是**金额**不是股票数）。与"风险中性化"不同（风险中性在基金经理组合层做）。
- 数学保证：每个 alpha 值**减均值** → 新数列和必为 0（可严格证明）。权重 = 该值 ÷ |所有值绝对值之和|。
- **market** 中性化：全市场减一个均值；**sector** 中性化：先按 sector 平分资金，再组内减均值。

## 一、课前：达分 → 顾问邀请流程（与文档 18/24 互补）

- 达 10,000 分后 **2–3 天**（当天不计）收系统自动提醒，点"是"进入 **workday** 填问卷。
- 未收到邀请的两类原因：
  1. **地区非运营**：填了日本/澳大利亚等无 consultant 项目的区域。
  2. **账户异常行为**：最典型——每天登录第一秒就回测出一个"可提交"Alpha（无学习痕迹、像机器刷），触发风控。
- 交 **15+ 个 Alpha** 不是门槛，而是**加速审核**（工作人员按提交量优先处理），处理完→背调公司→返回→签顾问合同→回传开通权限。
- 背调整体约 **1 个月**，春节更长。

## 二、作业讲评 1：trade_when 算子（降换手率）

### 三参数语义
`trade_when(开仓条件, 平仓条件, alpha 值)`
- **平仓条件**（第三参数位置，优先判断）：成立 → 当天直接平仓，不交易（原有股票卖出，无则不动）。
- **开仓条件**（第一参数）：平仓不成立时才看；成立 → 用新算出的 alpha 值更新；不成立 → **继承上一期 alpha 值**（alpha 值不变）。

### 课堂演算例（只看 A 公司，close 为判断条件，alpha 值由别的表达式算出）
| 时间 | close | 平仓<2? | 开仓>10? | 当日 alpha 值 | 说明 |
|---|---|---|---|---|---|
| 大前天 t3 | 5 | 否 | 否(5) | 继承（无前值→空） | 不开仓不更新 |
| 前天 t2 | 11 | 否 | 是 | **0.4** | 开仓更新 |
| 昨天 t1 | 4 | 否 | 否(4) | 继承 **0.4** | 不更新 |
| 今天 t0 | 5 | 否 | 否(5) | 继承 **0.4** | 不更新 |

> 平仓条件例：close < 2 直接平仓（如 C 公司股票昨天收盘 < 1，alpha 值必为 none/平仓）。

### 关键辨析（易错）
- alpha 值不变 ≠ 仓位不变：B 股票 alpha 值若变大，A 相对变小，A 的头寸占比也要调 → 仍可能买卖。
- trade_when 的核心价值：**降低 alpha 值变动频率 → 降低 turnover、降低成本**。这是事件驱动/低换手 Alpha 的通用写法（详见文档 16）。

## 三、作业讲评 2：数据字段更新频率（six tips 实战）

- 读数据**先定性**（看 description 搞清楚是什么），**再定量**（用 six tips 看频率）。
- 例：`cash_flow_from_financing_activity_forecast` 属**分析师数据集**，是"融资活动现金流的预测是否修订（revision）/新增（new）"。
- 正确 setting：Neutralization=none、Decay=0、**NaN Handling 关掉**（backfill off），否则缺失值被处理掉，反映不了数据本身。
- 用布尔阈值法感频率：
  - 条件设 5 天（周更）→ 仅 2–4 只股票有值 → 分析师紧盯、每周发预测。
  - 条件设月度 → ~23 家按月更新（必含上面周更的）。
  - 季度/年度 → 200+ 家常被关注。
- **直觉结论**：此数据全年更新极少 → 用它做的 Alpha **turnover 天然低**；若做出 turnover 60 的 Alpha，基本是引入了噪音掩盖了数据本身。好 Alpha 要对"食材"有体感。

## 四、正题：Neutralization（中性化）与 Group

### 4.1 什么是多空中性化
- 平台强制：**一半的钱做多、一半的钱做空**（是**金额**一半，不是股票数量一半）。
- 目的：股灾全市场下跌时，空头头寸保护组合；量化流派是**统计套利**——不追求每支股票都赚，追求整体（1000/3000 只）组合赚钱。
- 与**风险中性化（risk neutralization）**区分：风险中性在基金经理把交易发给交易部门那一层做，不是本课讲的多空中性化。
- 设 Neutralization=**none** 表示不做额外加工，数值原汁原味（所以探查数据时要关掉）。

### 4.2 数学实现（可严格证明）
- 要让金额多空中性，需 alpha 值**有正有负且正绝对值之和 = 负绝对值之和**。
- 做法：对每个 alpha 值**减去全样本均值**。
  - 例：值 [2, 4]，均值 3 → [2-3, 4-3] = [-1, 1]，和为 0。
  - **定理**：数列每项减其均值，新数列和必为 0（代数恒等式，无需讨论）。
- 权重分配：用每项绝对值 ÷ **所有项绝对值之和**，得该股票应投资金比例。
  - 例：8 只股票 alpha 值均值 -18.06，每项减 -18.06 后新数列和必为 0；再按 |值| 和归一化分钱。
  - 本例 long count=7、short count=1，仍达到中性化（证明是金额中性，非数量中性）。
- 每日盈亏 = 权重 × 涨跌幅 × 本金；累加得当日 PNL，连起来画累计曲线（即平台那条线）。

### 4.3 Sector 中性化（group 的简化版）
- 选 sector 时：先数有几个 sector，资金平分（2 个 sector → 各 50 块）；再在**每个 sector 内部**做"减均值"中性化。
- 即：组间平分资金、组内多空中性。这就是 `group_neutralize(x, group)` 的底层逻辑（详见文档 16/24：group_neutralize 与 Simulation Settings 的 Neutralization 可互换，配 None/0/0）。

## 五、本课要点回顾（考试易考）

1. 达分→workday 问卷→交 15+ Alpha 加速→背调~1 月→合同回传开通。
2. trade_when 三参数：平仓优先，开仓更新，否则继承上期 → 降 turnover。
3. 探查数据频率：neutralization=none、decay=0、NaN handling off；布尔阈值法读分布。
4. 中性化=多空中性（金额一半多一半空），非风险中性；减均值保证和为 0。
5. market 全市场减均值；sector 先平分资金再组内减均值（即 group_neutralize 原理）。
