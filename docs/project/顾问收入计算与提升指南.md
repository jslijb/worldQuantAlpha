## 一、顾问收入四大组成部分

顾问收入由以下四部分构成：

| 收入类型 | 金额范围 | 核心决定因素 |
|---|---|---|
| **Base Payment（日常津贴）** | 1–60 USD / Alpha / 天 | Value Factor、Theme、Quantity、Quality、Self Growth |
| **Quarterly Payment（季度奖金）** | 100–25,000 USD / 季度 | Weight Factor、Value Factor、OS 表现 |
| **Competition（比赛奖金）** | 视比赛名次而定 | 各类 BRAIN 比赛 / 研究小组双周评比 |
| **Referral Bonus（推荐奖金）** | 200 USD / 成功推荐 | 被推荐人成为顾问并提交 ≥10 天 Alpha |

## 二、Base Payment（日常津贴）详解

### 2.1 Regular Alpha

- **每日区间**：1–60 USD。
- **结算逻辑**：平台每日结算，北京时间下午 2 点前更新。
- **计算方式**：可粗略理解为 `Group_Rank(Score, value_factor)`——平台按 Value Factor 把顾问分组，你的 Value Factor 决定了当日 base payment 的上限和下限。
- **每日数量上限**：Regular Alpha **最多 4 个**。

### 影响 Base Payment 的四个因素

| 因素 | 说明 | 提示 |
|---|---|---|
| **Quantity Factor（数量因子）** | 提交数量是入参，但不是简单的\“一个多少钱\”。对新人加成不明显。 | 每天 1–2 个即可，不用猛堆数量。 |
| **Quality Factor（质量因子）** | Theme（主题任务）主要影响这部分的乘数；完成 Theme 内 Alpha 有额外奖励。 | 看平台右上角小铃铛 announcement。 |
| **Self Growth Factor（自我成长因子）** | 与自己历史数据相比是否有提升。 | 持续进步比一次性爆发更重要。 |
| **Value Factor（价值因子）** | 决定你每日 base payment 的上下限区间。 | **新顾问前三个月最主要目标就是提高 Value Factor。** |

> 通常 Alpha 表现越好、地区和 universe 越分散、相关性越低，Quality Factor 越高。

### 新人节奏建议

- **每天 1–2 个 Alpha** 是比较推荐的节奏。
- 一个月 30–60 个 Alpha，可以维持稳定的 Value Factor 表现，也满足季度奖条件。
- **1.5 USD 大法**：如果当天只提交 1 个 Alpha，但 Base Payment 在 1.5 USD 以上，说明这个 Alpha 质量不错；如果只有 1.2 USD，可能要反思质量。

### Super Alpha Base Payment

- **解锁条件**：累计提交满 **100 个 Alpha**（含用户阶段提交的）。
- **定义**：从自己提交过的 Alpha 中筛选组合，形成更强的信号。
- **金额范围**：每日 1–60 USD，与 Regular Alpha **分别计算**。
- **每日上限**：**1 个**。
- 符合 Super Alpha 的人数更少，竞争压力小，大神常能拿到 60 USD 封顶，普通顾问也能拿到 10 USD 左右。

## 三、Quarterly Payment（季度奖金）详解

### 基本条件

- 每个自然季度，有 **20 天提交过 Alpha**，即可获得当季度季度奖金资格。

### 发放周期

- **每季度末发放，但发放的是上季度的季度奖**。
- 例如：
  - 12 月底发放的是 **Q3** 的季度奖；
  - 3 月底发放的是 **Q4** 的季度奖；
  - 以此类推。

### 奖金范围与 Genius Level

季度奖金取决于你的 **Genius Level**，分为四个区间：

| Genius Level | 季度奖金范围 |
|---|---|
| 新人 → Expert | 200 USD – 2,000 USD |
| Master | 2,000 USD – 8,000 USD |
| 更高阶 | 最高可达 **25,000 USD** |

### 决定因素

- **Weight 和 Value Factor**。
- **Weight 需要时间积累**：当你的 Alpha 被 WorldQuant 选中进入实盘，Weight 会持续积累；只要 Alpha 不失效，Weight 会越滚越多。
- **OS（样本外）表现**：平台用你看不到的 2022–2024 年数据检测 Alpha 在真实市场环境下的表现。

### 查询路径

平台顶部导航栏：**Competition → Consultant**，可查看自己和别人的 Weight Factor 与 Value Factor。

## 四、竞赛奖励（Competition）

- 平台不定期推出顾问比赛，类似 Kaggle，每次持续 **4–6 个月**，每次有特定主题。
- 例如 ATOM 比赛：要求使用 single dataset，在 GLB 和 USA Delay 1 下提交 Alpha。
- 比赛 Alpha 的日常薪资照常计算，名次靠前还有额外奖金。
- **研究小组**：提交满 30 个 Alpha 后可进入研究小组，参与双周评比，前三名有额外一次性奖励。

---

## 五、推荐奖励（Referral Bonus）

- **每成功推荐一人**：200 USD。
- 被推荐人注册时需填写你的 **User Alias**。
- 被推荐人成为顾问后，需在 **10 个不同自然日** 提交 Alpha。
- 被推荐人需保持顾问身份 **1 个月以上**。
- 每人只能有一个顾问账号，不能开小号。
- 当前有限时推广：被推荐人达标后也可获得 100 USD。

---

## 六、税务代扣代缴

- 平台按**劳务所得**代扣代缴。
- **800 RMB 以内免税**；超过 800 部分扣 **20%**。
- 每年 4 月进行上一年个税汇算清缴，根据实际情况退税或补税。

---

## 七、薪资发放周期

### 发放频率

- **Base Payment**：每 **2 个月** 发放一次。
- **Quarterly Payment**：每 **季度** 发放一次。
- 因此每年 1、3、5、6、7、9、11、12 月都可能有发薪日。

### 账单与打款规则

- 只有当期截止前成为 **full consultant**（填写完银行卡），且账单金额 **> 10 USD**，才会生成账单；否则累计到下一周期发放。
- 发钱前会收到邮件，需在 **Workday** 内确认金额和明细后才会到账。
- 银行卡填写错误或有限额会导致收不到钱。
- Base Payment 每日更新；Quarterly Payment 只在下季度末发放前才会在 Other Payment 中显示。
- 比赛奖金、推荐奖金、一次性津贴**随 Base Payment 发放**；只有季度奖金随 Quarterly Payment 发放。

## 八、如何提高 Base Payment

![如何提高 Base Payment 流程图](C:/Users/jslij/.workbuddy/clipboard-images/clipboard-2026-09-05T14-02-22-736Z-f2668166.png)

### 八大方向

| 方向 | 具体做法 |
|---|---|
| **Quantity Factor：每天提交 4 Regular + 1 Super** | 达不到就再多提交；高手可挑战 Super Alpha。 |
| **Quality Factor：做 Theme Alpha** | 定期查看 announcement 和 Theme Calendar，让多数提交匹配当前 Theme。 |
| **降低 Alpha 相关性** | 同一顾问 leaderboard 的 prod corr 接近 0.7 时要警惕，降低重复度。 |
| **扩展 Universe** | 在 liquid/large universe 中提交，尝试更大、流动性更好的股票池。 |
| **提升 Value Factor** | 提交前做额外检查；确保 Alpha 在 rank/signed 后仍有 70%+ Sharpe；保持 margin > 4bps；不要为了过相关性检测而加噪音。 |
| **避免过度集中** | 如果 50%+ Alpha 集中在单一 region/turnover/data field，可能降低 Value Factor。 |
| **Self Growth：持续进步** | 计算近几周提交 Alpha 的平均表现（Sharpe、correlation 等），不断优化。 |
| **保持提交节奏稳定** | 每日提交数量稳定或递增，不要三天打鱼两天晒网。 |

### 好 Alpha 的常见特征

- 在 sub-universe 和 super-universe 都能达到 **70% Sharpe**；
- **Turnover < 30%**；
- **Margin > 4bps**；
- 不要为了过相关性检测而加入噪音（避免明显 overfitting）。

## 十、新顾问行动清单

- [ ] 前三个月优先**提高 Value Factor**，不要只追求数量。
- [ ] 每天保持 **1–2 个高质量 Alpha** 的节奏。
- [ ] 关注右上角 **Theme announcement**，做 Theme Alpha 拿质量乘数。
- [ ] 尽量分散 region、universe、data field，降低相关性。
- [ ] 累计到 **100 个 Alpha** 后解锁 Super Alpha，争取额外收入。
- [ ] 每季度保证 **20 天有提交**，拿季度奖。
- [ ] 填写正确的银行卡信息，发薪前在 Workday 确认账单。
- [ ] 每年 4 月做个税汇算清缴。
