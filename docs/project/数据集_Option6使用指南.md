# BRAIN Option6 隐含波动率数据集使用指南

> 来源：WorldQuant BRAIN 官方 Option6 数据集说明。Option6 位于期权类别 > 期权波动率子类别下。

---

## 一、数据集概览

| 属性 | 说明 |
|---|---|
| **数据类型** | 仅 MATRIX |
| **延迟** | Delay 0（131 个字段）、Delay 1（133 个字段） |
| **股票池** | TOP3000、TOP500、TOP200、TOP1000、TOPSP500、TOP2000 |
| **覆盖率** | USA/D1 约 95%，USA/D0 约 97% |

> 隐含波动率（IV）是权益市场研究最多的数字之一。Option6 关注的不只是"今天 IV 是多少"，而是波动率曲面的形态、远期预测以及模型信心。

---

## 二、字段六大家族

### 2.1 固定期限隐含波动率

- 把 IV 曲面值插值到固定期限。
- 主要字段：
  - `opt6_30div`：短期限固定期限隐含波动率（字段名写 30，但底层窗口是 20 天，用作短锚点）
  - `opt6_vimta3m`：第三个日历月到期期权的平值隐含波动率
  - `opt6_ivpctile1m`：一个月区间百分位
- 特性：序列移动缓慢，插值充当过滤器，**表现得像宏观类数据**。
- 建议使用：约一个季度窗口的 `ts_mean`、`ts_av_diff`、`ts_zscore` 等，比短窗口差值效果好。

---

### 2.2 波动率曲面形态（偏斜、斜率、曲率）

IV 曲面被参数化为水平、斜率、曲率：

| 字段 | 含义 |
|---|---|
| `opt6_slopeavg1m` / `opt6_slopeavg1y` | 斜率滚动平均 |
| `opt6_slopestd1y` | 斜率年度离散度 |
| `opt6_slopepctile` | 一年百分位排名 |
| `opt6_slopeinf` | 隐含无穷斜率 |
| `opt6_derivinf` | 外推到无穷行权价极限的曲面隐含导数 |
| `opt6_vired` | 从平值向价外看涨移动时，波动率微笑倾斜速度。大 = 微笑急剧弯曲；小 = 近乎平坦 |

- **斜率**：捕捉下行看跌 vs 上行看涨的需求。
- **导数**：捕捉尾部风险 vs 主体风险的需求。
- 这些形态信号比原始 IV 更丰富，常在**板块层面均值回归**。

---

### 2.3 预测家族

Option6 的标志性特征：携带**20 天远期预测**及拟合优度。

| 字段 | 含义 |
|---|---|
| `opt6_2rtscf` | 20 天已实现波动率预测的 R²，衡量模型预测已实现波动率的好坏 |
| `opt6_fcstr2imp` | 隐含波动率预测的 R²，衡量模型预测 20 天后隐含波动率的好坏 |

- R² 字段不是方向性的，而是**信心信号**。
- 预测 R² 稳定且高的股票 = 期权模型"处于合适状态"，来自该数据集的信号权重更高。
- **理想用法**：作为 `trade_when` 的闸门。

```
trade_when(ts_mean(opt6_fcstr2imp, 60) > 0.5, signal, -1)
```

---

### 2.4 盈利效应序列

同时提供"含盈利"和"剔除盈利"两个变体：

| 字段 | 含义 |
|---|---|
| `opt6_impliediee` | 市场隐含的盈利效应 |
| `opt6_absavgernmv` | 与下一次盈利公告相关的股票价格平均绝对百分比变动 |
| `opt6_lastern` | 最近一次盈利公告日期 |

> ⚠️ `opt6_nexterntod` 和 `opt6_lasterntod` 已弃用，避免使用。

- 这些字段从活跃期权曲面持续计算，不是稀疏事件字段。
- **不需要激进回填**，短至 5 天的 `ts_backfill` 即可处理偶发缺失日。

---

### 2.5 股息簇

常被忽视但很有价值的部分：

| 字段 | 含义 |
|---|---|
| `opt6_divyield` | 年化股息收益率 |
| `opt6_divfreq` | 股息频率 |
| `opt6_divamt` | 股息金额 |

- 这些是期权定价引擎的输入，本质上是依托在期权数据集内的**基本面数据**。
- 相比纯基本面数据集，**不那么拥挤**，是较好的起始点。

---

### 2.6 跨资产比率

| 字段模式 | 含义 |
|---|---|
| `opt6_ivspyratio` / `opt6_ivspyratioavg1y` | 相对 SPY 的 IV 比率及 1 年平均 |
| `opt6_ivetfratio` / `opt6_ivetfratioavg1m` | 相对匹配板块 ETF 的 IV 比率及 1 个月平均 |
| `opt6_correlspy1m` / `opt6_correletf1y` | 配对相关性 |

- 使用比率字段意味着**跨资产调整已经做完**。
- 在市场层面而非板块层面中性化这样的信号，通常更干净。

---

## 三、使用建议

### 3.1 谨慎回填

- Option6 字段从活跃期权曲面持续更新，**长回填窗口会引入过时的期权定价假设**。
- 短至 **5 天的 `ts_backfill`** 足以处理偶发缺失日。
- 插值 IV 字段和预测 R² 字段密集，**完全不需要回填**。

### 3.2 中性化建议

- 建议对期权数据集采用**市场或板块中性化**。
- 基于原始波动率曲面字段（斜率、IV 水平、导数）的信号，适合**板块中性化**（波动率按板块定价）。
- 基于 `ivspyratio` 或 `ivetfratio` 的信号已经移除市场暴露，适合**市场中性化**。

### 3.3 留意时间尺度

- 固定期限 IV 字段和 `avg1m`、`avg1y` 已经平滑，再叠加 `ts_mean` 是多余的。
- 优先使用：
  - `ts_delta`
  - `ts_av_diff`
  - `ts_zscore`
- 窗口约 **一个季度（60 天左右）**。
- 问"最近 5 天发生什么变化"大多在度量噪声。
- 问"今天相对于过去 60 天所处的位置"才度量信号。

### 3.4 在两个 Option6 字段之间使用 ts_corr 要谨慎

- 许多字段在机制上相关：IV 锚定于 HV，斜率受曲面形态约束。
- 它们之间的相关性往往捕捉的是**数据集内部结构**，而非真实跨资产行为。
- **建议替代方案**：
  - 使用 `ts_regression(..., rettype=0)` 提取残差。
  - 或构造标准化价差：`subtract(ts_zscore(X, 60), ts_zscore(Y, 60))`。

### 3.5 将预测信心用作过滤器

- 在过去一个季度中 `opt6_fcstr2imp` 稳定偏高的股票，是模型"处于合适状态"的股票。
- 软信号通过 `trade_when` 门控后会显著改善。

```
trade_when(ts_mean(opt6_fcstr2imp, 60) > 0.5, signal, -1)
```

> 这是一种低调但强大的技巧。

## 五、常见考点

1. **Option6 数据类型是什么？** → 仅 MATRIX。
2. **`opt6_30div` 的底层窗口是多少天？** → **20 天**。
3. **R² 字段代表什么？** → **模型预测信心**，不是方向信号。
4. **Option6 字段需要长回填吗？** → 不需要，**5 天 ts_backfill 足够**。
5. **斜率捕捉什么？** → 下行看跌 vs 上行看涨需求。
6. **`ivspyratio` 字段适合用什么中性化？** → **市场中性化**（已移除市场暴露）。
7. **原始 IV 曲面字段适合用什么中性化？** → **板块中性化**（波动率按板块定价）。
8. **两个 Option6 字段相关时优先用什么？** → `ts_regression(..., rettype=0)` 或标准化价差。
