## TL;DR 考试速查卡

- **Alpha = 数据字段（data field）+ 算子（operator）** 组合成的数学模型。
- 平台数据字段已超 **16 万**（早期资料称 15 万+）；算子随权限 **50 个起**，组合空间近乎无穷。
- 好 Alpha = 佳肴：**data field = 食材，operator = 烹饪方法**。
- 两类最易入门的数据：**Fundamental（基本面）** 与 **Price-Volume（量价）**。
- **Fundamental**：三张报表（资产负债表 / 利润表 / 现金流量表），更新最快**季度**，部分半年/年；不是每天都有值。
- **Price-Volume**：open/high/low/close/vwap/adv20，只要当天交易就更新。
- **data field ≠ dataset**：field 是一张表（CSV），dataset 是装表的文件夹；回测框里要填 **field 名**（unique），不能填 dataset 名。
- **delay 0 = 盘中交易**：close 在 delay 0 下是"收盘前近似价"，很多数据盘中根本没有。
- 定量了解数据：把 field 直接回测（neutralization=none、decay=0），用 **long/short count** 读覆盖度；用**布尔判断算子**问阈值，画累积直方图看分布。

## 二、核心：Alpha 由 data + operator 组成

- Alpha 本质是一个**函数**：输入数据 → 经 operator 运算 → 输出一个预测得分（分数越高，对应股票越该做多）。
- 上节课作业 `-close`：data field 是 `close`，operator 是负号（数轴上取反）。`rank(close)` 也是 operator+field。
- **组合空间无尽**：16 万数据字段 × 50+ 算子，两两、三三、四四组合，全地球算力都算不完——这正是需要众多研究顾问一起挖信号的原因。
- 商业模式一句话：平台有数据基础设施，你有脑力，一拍即合，在金融市场用纷繁数据找可交易信号。

## 三、食材（Data）：两类最易入门的数据

### 1. Fundamental（基本面数据）
- 就是财务报表，通常三张：**资产负债表（balance sheet）/ 利润表（income statement，也称损益表）/ 现金流量表（cash flow statement）**。
- 含资产、负债、股东权益、各类费用（广告/人工/营销/薪酬）、进货成本等经济学常见名词。
- **更新频率**：上市公司财报需经审计后披露，最快**季度**；有的公司半年、有的年度；同一张表里不同公司频率也可能不同（季度/半年/年混存）。
- 拿到 `asset` 这类字段时要心里有数：**不是每天每家公司都有值**，有的季度才有、有的退市了就没了。
- 重要性：大股东、专业/机构投资者都看同一份财报，信号明确，很多 Alpha 易从中产生。

### 2. Price-Volume（量价数据）
- `open` 开盘价、`high` 最高价、`low` 最低价、`close` 收盘价。
- `vwap` = Volume Weighted Average Price，**成交量加权均价**（当天均价，非简单算术平均）。
- `adv20` = Average Daily Volume，**过去 20 天平均成交量**。
- **更新频率**：只要当天有交易（未停牌/未退市），开盘就有值，至少每日更新。

> 更多数据集（新闻、情绪、分析师、关系等）在 Data Explorer 自行探索，详见文档 17。

## 四、Data Explorer：怎么找数据

- 打开平台 **Data Explorer**，搜索框支持**自然语言（英文）**，输错单词也能猜；**中文搜索效果不佳，需先翻译**。
- 搜索结果分两类：
  - **Field（数据字段）** = 一张表（CSV 文件）。
  - **Dataset（数据集）** = 装表的**文件夹**。
- **关键辨析**：回测框里要填 **data field**（每个 field 命名 unique，一输就定位），**不能填 dataset 名**（平台不知道用哪个文件）。
- 点进 dataset 看 **Description** 了解内容；**Dataset ID** 是取该集全部信息的钥匙（命名无特殊规律）。
- 右上角先设好 **Region** 与 **Delay** 再搜：不是所有数据在所有区域都有（如有的中国有其美国无）。

### delay 的盘中语义（易错）
- `delay 0` = 盘中就利用该数据交易；`delay 1` = 收盘算好 Alpha、次日开盘交易（上节课作业已学）。
- **close 在 delay 0 下不是当天真实收盘价**，而是"数据采集时收盘前的近似价"。
- 很多数据盘中根本没有（如当天真实收盘价、部分成交量），delay 0 会缺失。

## 五、定量了解数据：Six Ways to Evaluate New Datasets

> 论坛帖《six ways to quickly evaluate new data sets》（搜 "six ways" 或 "six tips" 即可找到）。本课挑前两条讲，核心是**先定性、再定量**。

### 方法 1：直接回测 data field，读 long/short count（覆盖度）
- 把 data field 直接输进回测框，**Neutralization 设 none、Decay 设 0**，保持数值"原汁原味"不被加工。
- 平台规则：输入正数→做多，负数→做空（所以中性化设 none 时，看正负就知道方向）。
- **long count** = 平均被做多的股票数；**short count** = 平均被做空的股票数。这是**全年日均**（把每天的值加起来 ÷ 交易日数，约 200–250 天），不是某一天。
- 例：某 field 在 top3000 下只有 2300+ 只股票有值 → **coverage ratio ≈ 2300/3000**；且"只有正数"也是关键信号（说明值域受限）。

### 方法 2：用布尔判断算子问阈值，画累积直方图（分布）
- 写法：判断 data field `!= 0` → 输出 1（做多），否则 0（不交易）。此时只看 long count 即可。
- 逐步抬高阈值问：`> 0.25` 多少只、`> 0.5` 多少只、`> 0.75` 多少只、`> 1` 有没有……
- 例：2300+ 有值，>0.25 有 1800+，>1 为 0 → 值域在 **[0, 1]**，很可能是已归一化/规划过的数。
- 由此可分段（0–0.25 / 0.25–0.5 / 0.5–0.75 / 0.75–1）画出**累积直方图**，掌握分布。
- 原理：用"是与否"的判断式无限次回测，可反推每个股票每个值的统计特征（平台不暴露原始数据，但暴露统计特征）。

## 六、本课要点回顾（考试易考）

1. Alpha = data field + operator；组合空间无尽。
2. Fundamental 季度更新、Price-Volume 日更新，频率决定了 Alpha 的 turnover 上限。
3. data field（表）≠ dataset（文件夹）；回测填 field 名。
4. delay 0 是盘中交易，close 是收盘前近似价。
5. 评估新数据：neutralization=none + decay=0 直接回测读 long/short count（覆盖度）；布尔阈值法读分布。
