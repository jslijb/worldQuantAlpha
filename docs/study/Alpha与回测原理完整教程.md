## 一、什么是 BRAIN Consultant（通俗版）

BRAIN Consultant 可以简单理解为**开放给所有人的量化研究兼职岗位**。

- **工作方式**：通过 Python 脚本或平台界面操作，利用 WorldQuant 提供的 15 万+ 海量数据、算力和 API 框架，去挖掘有效的数据特征。
- **收入来源**：根据提交的 Alpha 数量、质量，以及你在平台的\“等级（value factor）\”来拿钱。签了顾问协议，按平台固定付款周期发工资。
- **收入波动**：每天都能看当天收入；前三个月是\“试用期\”，收入少一些；三个月后如果表现好、级别提升，收入可能翻几倍甚至几十倍。不同人差异很大，几百到几万都有。
- **冲突限制**：如果你当前在金融机构或金融科技公司任职，可能因为利益冲突无法兼职做顾问。

一句话：**WorldQuant 出数据、出算力、出框架，你出想法（Alpha），平台回测你的思路，好思路拿去实盘，你按贡献拿分成。**

## 二、Alpha 入门（官方原文）

### Alpha

在 BRAIN 中，\“Alpha\”指的是一种以**表达式**编写的**数学模型**，它会对不同的工具（股票）下注不同的头寸（权重），并预期在长期内实现盈利。

在用户输入由数据、算子和常量组成的 Alpha 表达式后，系统会对每个工具评估该输入代码以构建投资组合。然后，BRAIN 会根据表达式的值，在一日周期内按比例投资于每个工具。该过程每天重复。

### Alpha 生命周期

1. **产生思路**：浏览博客、期刊、研究论文，产生交易想法。
2. **输入表达式**：在 BRAIN 中输入 Alpha 表达式，并对原始 Alpha 执行一些操作（如截断、中性化、衰减）。
3. **回测**：BRAIN 对\“设置\”面板中所选宇宙（universe）的所有工具进行投资（做多或做空），并回测 PnL。
4. **评估结果**：查看\“回测结果\”页面，计算业绩（夏普比率、换手率、回报率）。
5. **修订或提交**：如果 Alpha 不够好，就修订思路；否则进入生产阶段。

### 权重

BRAIN 使用 Alpha 创建一个**权重向量**，每个权重对应于所选宇宙中的一只股票。根据中性化设置（按市场、行业、子行业或不做中性化），这些权重可以经过也可不经市场中性化处理。这会在回测期内为每天创建一个投资组合，随后可用于计算当天的盈亏（PnL）。

### 分配权重示例

假设输入表达式 `1/close`，设置：地区=美国，宇宙=TOP3000，延迟=1，衰减=0，中性化=无，截断=0。点击\“回测\”后，引擎会：

- 对 US:TOP3000 中的每只股票计算 `1/close`（使用前一天收盘价）。
- 得到一个 3000 个值的向量，每个值代表一只股票。
- 对该向量**归一化**（除以各值之和，使总和为 1）。
- 得到每只股票的权重（投资比例）。
- 如果账面规模（book size）为 2000 万美元，每只股票的投入 = 2000 万 × 该股票权重。
- 回测期内每天重复，每天计算总盈亏。

### 正权重与负权重

- **正权重**：多头头寸（买入，预期上涨）。
- **负权重**：空头头寸（做空，预期下跌）。
- 权重绝对值越大，仓位越大。

例如，100 美元多头 vs 100 美元空头在价格各变动 1% 时的收益：

| 价格变动 | 多头收益 | 空头收益 |
|---|---|---|
| 上涨 1% | +$1 | -$1 |
| 下跌 1% | -$1 | +$1 |

> 注：为简洁起见，未考虑股息、保证金和融资成本。

### BRAIN 是什么

BRAIN 是一个**基于网络的全球金融市场回测引擎**，旨在探索 Alpha 研究。它接受 Alpha 表达式作为输入，并绘制其盈亏（PnL）作为输出。

输入表达式会在历史日期的每一天针对每个金融工具进行评估，并据此构建投资组合。BRAIN 根据表达式的值投资于每个金融工具，建立头寸（买入或卖空），并为每个工具分配权重。然后，这些权重按账面规模（投资金额）进行缩放，并据此绘制 PnL 曲线。这些权重会随时间而变化。

## 三、BRAIN 如何运作（官方原文 + 配图）

### 核心直觉

想象市场数据是一个矩阵，每一行代表一个日期，每一列代表一只股票。例如，US TOP3000 中股票的收盘价矩阵：

![收盘价矩阵：行是日期，列是股票](C:/Users/jslij/.workbuddy/clipboard-images/clipboard-2026-09-05T09-54-37-891Z-ddfb2be5.png)

当你输入回测设置并点击 \“Simulate\” 时，BRAIN 平台会对五年区间内每个日期的市场数据矩阵评估 Alpha 表达式，对每个金融工具建立多头或空头仓位，生成 PnL 图表。

![点击 Simulate 后的流程：Alpha 表达式 + 模拟设置 → BRAIN Simulator → 建立多空仓位 → PnL Chart](C:/Users/jslij/.workbuddy/clipboard-images/clipboard-2026-09-05T09-54-37-893Z-07cc347b.png)

在幕后，生成最终 PnL 图表之前会执行**七个步骤**。

### 假设场景

为便于理解，假设回测股票池只有 8 只股票，使用市场中性化、Delay 1、Decay 0 来回测表达式 `rank(-returns)`。

这个表达式的基本假设是：**明天买入今天收益为负的股票，明天卖出今天收益为正的股票**（反转/均值回归思路）。

`rank` 运算函数会对输入值排名，返回 0 到 1 之间均匀分布的值。

### 步骤 1：计算 Alpha 向量

对每只股票计算表达式，生成给定日期的 Alpha 向量。

示例日期是 2 月 2 日，因为使用 **Delay 1**：用截至 T-1（2 月 1 日）的数据来创建截至 T（2 月 2 日）的 Alpha 向量。

引擎对负收益执行 `rank` 运算，生成一个对应每只股票的值的向量。收益最低的股票得到最高排名值，反之亦然。

![步骤 1：根据 2 月 1 日收益计算 2 月 2 日的 Alpha 向量（rank(-returns)）](C:/Users/jslij/.workbuddy/clipboard-images/clipboard-2026-09-05T09-54-37-895Z-d92edc32.png)

### 步骤 2：中性化（Neutralization）

从向量中的每个值中减去该分组中向量值的平均值，使所有向量值之和为 0。

分组可以是整个市场，也可以按行业（sector）、子行业（industry）或子行业分组（subindustry）执行。

假设对市场整体中性化：取 D 列平均值，从每只股票中减去，得到新向量，其和与平均值均为 0，正数之和等于负数之和。

![步骤 2：中性化——减去分组平均值，使向量中心在 0 附近](C:/Users/jslij/.workbuddy/clipboard-images/clipboard-2026-09-05T09-54-37-896Z-73b67734.png)

### 步骤 3：归一化（Normalization）

对结果值进行缩放，使 Alpha 向量值的**绝对值之和为 1**。这些值就是**归一化权重**。

例如：绝对值总和为 2.3，每个值除以 2.3，得到新向量。

![步骤 3：归一化——让权重绝对值之和为 1](C:/Users/jslij/.workbuddy/clipboard-images/clipboard-2026-09-05T09-54-37-897Z-4513201c.png)

### 步骤 4：分配资金

利用归一化权重，BRAIN 把虚拟资本（如 2000 万美元）分配给每只股票。

例如，某只股票权重为 -0.22，意味着要做 440 万美元空头；另一只为 +0.03，意味着投入 60 万美元多头。

![步骤 4：按权重把 2000 万美元分配给每只股票](C:/Users/jslij/.workbuddy/clipboard-images/clipboard-2026-09-05T09-54-37-898Z-78f8b5ab.png)

这就是**多空市场中性化**，是 BRAIN 构建 Alpha 预测模型的核心技术。借此，无论市场方向如何，策略都有可能盈利。

### 步骤 5：计算单日 PnL

根据次日观察到的股票收益，计算 Alpha 在次日产生的 PnL。

假设 2 月 2 日实际收益如 K 列所示：如果实际走势与预测相反就亏损，一致就盈利。把所有股票的 PnL 相加，得到当天总 PnL。

![步骤 5：用 2 月 2 日实际收益计算单日盈亏](C:/Users/jslij/.workbuddy/clipboard-images/clipboard-2026-09-05T09-54-37-899Z-8a3b3825.png)

### 步骤 6：滚动回测每一天

在数年的历史区间（**样本内期间 IS**）内，对每个日期重复步骤 1-5，得到每天的每日 PnL。

每天的权重表示当天要达到的仓位。权重乘以 book size 就是每只股票持有的美元价值。权重为负表示做空，为正表示做多，NaN 表示不分配资金。

你今天买入/卖出的股票价值 = 今天权重 - 昨天权重。投资组合一天内交易的百分比就是**换手率**。回测结果中报告的换手率是回测期间的平均每日换手率。

### 步骤 7：累计 PnL 与 PnL 图表

从样本内期间开始计算 Alpha 的累计 PnL，得到 PnL 图表。

默认情况下，BRAIN 会对权重进行归一化，创建一个价值 2000 万美元的股权投资组合。

![累计 PnL 图表（IS 期间：2016-2021）](C:/Users/jslij/.workbuddy/clipboard-images/clipboard-2026-09-05T09-54-37-900Z-afb1c878.png)

在此图中：
- **IS（样本内）**：2016 年 2 月 - 2021 年 1 月，是回测窗口中你能看到的部分。
- **OS（样本外）**：2021 年 2 月 - 2023 年 1 月，是回测窗口中你看不到的部分。提交 Alpha 后，平台会跑多项测试来分析 OS 期间表现。
- 通过 IS 和 OS 两项测试的 Alpha 可被称为**稳健的 Alpha（robust alpha）**。

### Decay（衰减）

如果设置 decay（例如 decay=3），最终权重向量会通过组合今天的值与前几天衰减后的值来计算。

![Decay 示例：用 2 月 1 日和 1 月 31 日的权重参与加权平均](C:/Users/jslij/.workbuddy/clipboard-images/clipboard-2026-09-05T09-54-37-901Z-fb1d320c.png)

加权平均公式：

![线性衰减公式](C:/Users/jslij/.workbuddy/clipboard-images/clipboard-2026-09-05T09-54-37-903Z-72406735.png)

Decay 给最近值分配更多权重，同时包含前几天信息，从而**降低换手率、减少交易成本**，防止 Alpha 变得过于敏感和反应性。

### 总结

一旦在 BRAIN 中输入 Alpha 表达式和回测设置，引擎就会执行上述操作：

1. 用历史数据计算每只股票得分；
2. 中性化（让多空平衡）；
3. 归一化（让权重绝对值和为 1）；
4. 分配虚拟资金；
5. 按实际涨跌算每天盈亏；
6. 滚动历史区间；
7. 画出累计 PnL 曲线。

如果启用 decay，还会把今天和前几天的权重做加权平均，让仓位变化更平滑。

## 四、大白话总结（面试/笔试够用版）

### 三句话讲清 BRAIN

1. **Alpha 是你写的\“选股公式\”**：它用数据、算子、常数组成一个数学表达式，告诉系统每天看好哪些股票、看空哪些股票。
2. **BRAIN 是\“历史模拟器\”**：你把公式丢进去，它用过去 5 年的真实数据，模拟如果每天按这个公式买卖，能赚/亏多少钱。
3. **最终产出是 PnL 曲线 + 各项指标**：包括夏普比率、换手率、回报率等，用来判断这个公式靠不靠谱。

### Alpha 回测的七步口诀

> 算得分 → 去中心 → 归一化 → 配资金 → 算盈亏 → 滚动测 → 画曲线。

| 步骤 | 人话 | 目的 |
|---|---|---|
| 1. 算 Alpha 向量 | 用昨天数据给每只股票打分 | 把想法变成数字 |
| 2. 中性化 | 多头和空头互相抵消，整体不赌方向 | 降低市场风险 |
| 3. 归一化 | 让所有权重的绝对值之和为 1 | 控制仓位规模 |
| 4. 配资金 | 按权重把 2000 万美元分给各股票 | 生成投资组合 |
| 5. 算单日 PnL | 用当天实际涨跌算盈亏 | 验证当天预测 |
| 6. 滚动每一天 | 历史上每一天都重复 1-5 | 获取完整盈亏序列 |
| 7. 累计画曲线 | 把每天盈亏加起来 | 得到最终 PnL 图 |

### 关键概念一句话

- **多头（Long）**：买入股票，盼涨。权重为正。
- **空头（Short）**：借股票卖出，盼跌。权重为负。
- **市场中性化**：让多空市值大致相等，不赌大盘涨跌。
- **Delay 1**：用昨天数据做今天的决策，避免未来函数。
- **Decay**：把今天信号和前几天信号加权平均，降低换手率。
- **IS（In-Sample）**：训练/回测期，你能看到的部分。
- **OS（Out-of-Sample）**：提交后平台才检验的隐藏期。
- **TEST**：更严格的最终检验期（部分赛制/提交流程中）。
- **稳健的 Alpha**：同时通过 IS 和 OS 测试的 Alpha。

### 顾问角色的通俗理解

- **门槛**：一般是平台积分/等级达到要求即可申请。
- **权限**：相比普通用户，顾问通常有更高的提交额度、更多数据/工具权限、可参与顾问专属 challenge。
- **收入**：= 提交数量 × 质量 × 个人 value factor（等级）。
- **禁区**：不能作弊、不能盗用他人 Alpha、不能在金融机构任职期间因利益冲突参与等。

## 五、笔试/面试考点速查表

| 考点 | 标准答案要点 |
|---|---|
| Alpha 是什么 | 表达交易思路的数学模型；对不同工具分配权重；预期长期盈利 |
| BRAIN 是什么 | 全球金融市场回测引擎；输入 Alpha 表达式，输出 PnL 曲线 |
| 权重如何产生 | Alpha 表达式 → 中性化 → 归一化 → 得到权重向量 |
| 正/负权重含义 | 正=多头，负=空头；绝对值越大仓位越大 |
| 中性化作用 | 让分组内多空抵消，降低系统性风险 |
| 归一化作用 | 让权重绝对值和为 1，统一仓位规模 |
| Delay 1 含义 | 用 T-1 数据做 T 日决策，避免 lookahead bias |
| Decay 含义 | 当前权重与历史权重加权平均，平滑仓位、降低换手 |
| 换手率 | 一天内交易金额占 portfolio 的比例；回测显示平均每日换手率 |
| IS / OS / TEST | IS=样本内（可见回测期）；OS=样本外（隐藏验证期）；TEST=更严格最终检验期 |
| 稳健 Alpha | 同时在 IS 和 OS 上表现良好 |
| Consultant 收入 | 取决于 Alpha 数量、质量、个人 value factor；有试用期；金融机构在职可能冲突 |
| 平台禁止行为 | 作弊、盗用、违反利益冲突规定、滥用系统漏洞等 |
