## 一、报告核心（按提供的摘要归纳）

### 1. 三个因子
| 因子 | 定义 | 含义 |
|---|---|---|
| Turn20 | 20 日换手率均值 | 换手率水平（传统量能因子） |
| **STR** | `std(Turn20)`，即换手率稳定性 | **换手率波动越小 = 换手越稳定** |
| **UTR（优加换手率）** | Turn20 按 STR 分组做条件符号切换后再处理 | 组合因子 |

- 报告实测：**UTR 与 Turn20 的相关性仅为 0.42** —— 两者虽同源（都来自换手率），但条件化后成为低相关的两个信号，这是本报告最关键的实证。
- 单因子测试：换手率稳定性因子（STR 类）IC 与 ICIR 表现优于传统换手率因子（报告表1-5）。

### 2. 组合方式探索（报告第四部分，表6-10）
- 分组测试发现：**Turn20 与 UTR 的因子强度越高，选股能力反而越弱** —— 即不能用简单的加权/等权合成。
- 按换手率稳定性分组后，**换手率水平的符号发生翻转**：
  - 换手**稳定**的样本（`rank(STR) < 0.5`）：**低换手率**股票表现更好（传统反转逻辑）；
  - 换手**不稳定**的样本：**高换手率**股票表现更好（交易热度/关注度逻辑）。
- 实现方式（报告原文写法）：条件符号切换 —— `rank(-nan_mask(Turn20, if_else(rank(STR) < 0.5, 1, -1)))`。
- 条件切换后的因子需要**剔除右尾极端样本**才可提交（报告用 `left_tail(..., maximum=0.98)`），代价是 IC 下降但可获得可交易的纯净组合。

## 二、移植到我们（USA / TOP3000 / BRAIN）战场的可行性核对

**以下均为 2026-09-14 在平台实测的结果，非推测：**

| 报告所需 | USA 平台状态 | 结论 |
|---|---|---|
| `cap`（市值，用于分组） | ✅ MATRIX 字段存在 | 可用 |
| `sharesout` | ✅ MATRIX 字段存在（w96_b 已用过） | 可用 |
| `volume` | ✅ 基础 PV 字段 | 可用 |
| `bucket` | ✅ 在 66 个算子清单内 | 可用 |
| `group_neutralize` / `group_rank` / `group_mean` | ✅ | 可用 |
| `if_else` | ✅ | **条件符号切换可实现** |
| `ts_rank` / `ts_std_dev` | ✅ | STR/Turn 可实现 |
| `rank` / `add` / `trade_when` | ✅ | 可用 |
| **`nan_mask`** | ❌ **不在算子清单内** | 须改用 `if_else` / `trade_when` 替代 |
| **`left_tail`** | ❌ **不在算子清单内** | 右尾剔除须改用 `winsorize`/`quantile`/`trade_when` 近似 |
| **`right_tail`** | ❌ 不在算子清单内 | 同上 |
| CHN 区域数据 | ❌ 账号无权限（同日已实测 `region=CHN` 返回 0 字段） | **不可直接复现报告结果** |

**迁移后的 USA 等价写法（本次实际使用）：**
```
STR  = ts_std_dev(volume/sharesout, 20)
TURN = ts_rank(volume/sharesout, 20)
UTR  = if_else(rank(STR) < 0.5, TURN, -TURN)
CAPG = bucket(rank(cap), range="0.1, 1, 0.1")      # 市值十分位分桶
→ group_rank(信号, CAPG)                            # 用市值分桶代替 subindustry 分组
```

## 三、对我们当前困局的价值（相关性墙）

我们已提交 57 个 Alpha，Uniqueness 0.52，最拥挤的成因是**所有因子共享同一批引擎腿**（cash45 / cfoev45 / PV 反转 / vol）。本报告给出两个**结构级**（而非换字段级）的破墙思路：

1. **换分组维度：`bucket(rank(cap))` 市值分桶**
   我们历史上只用过 SUBINDUSTRY / INDUSTRY / market 分组。市值分桶是**全新的分组维度**，直接改变 PNL 构成 → 可能把与在产 Alpha 的相关性压到 0.7 以下。
   （同日实测：SLOW_AND_FAST 中性化账号不可用；batch104 的隔夜距离/条件切换新结构 solo 质量崩。市值分桶是当天唯一未证伪的结构级杠杆。）

2. **给拥挤腿本身做条件化，而不是再加一条腿**
   报告证明：同源因子（Turn20 与 STR）经条件符号切换后相关性可降到 0.42。
   对照我们的教训：同族骨架换腿扰动 corr 下限已被顶到 0.81（batch74/78 实证），**"同骨架换一条腿"已死**，但"**对某条腿做条件符号切换**"从未在骨架里试过——这正是报告的路子。

3. **元教训（与我们实证互证）**
   报告"因子强度越高组合越差"与我们"优秀量价因子 PnL 殊途同归（corr 0.8+）"是同一件事的两面：**同源信号无论怎么加权都趋同**。破局只有两条：叠加不同数据源（我们已做 analysis4/fnd2 锚）、或对同一数据换数理方法处理（条件化/分桶/拆分——我们刚开始做）。
