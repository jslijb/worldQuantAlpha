## 三、可移植到 USA 战场的 5 个技术点（按优先级）

1. **隔夜/日内/日间收益拆分（最有价值）**。
   文章把收益拆成 日间 `close/ts_delay(close,1)-1`、日内 `close/open-1`、隔夜 `open/ts_delay(close,1)`。
   隔夜收益异象（Lou-Polk-Skouras 2019）在**美股显著**——这正好是我们没用过的新信号轴。
   隔夜距离：`abs(open/ts_delay(close,1) - group_mean(open/ts_delay(close,1),1,market))` 再做 20 日均值。
   → 可替换骨架里最拥挤的 `-ts_delta(close,10)` 腿（该腿与已提交池 corr 0.75-0.93 的主因之一）。

2. **条件符号切换结构（新算子用法）**。
   `波动率 < 市场均值 ? -收益 : 收益`——"低波动标的做反转、高波动标的跟动量"的可知性逻辑。
   我们之前所有候选都没用过"截面比较后翻转符号"这个结构，结构层面的差异才可能压 corr，比换字段更根本。
   所需算子全部可用：ts_mean / ts_std_dev / group_mean / 三目 ?: / abs（operators.json 已核）。

3. **换手距离（换手率的新用法）**。
   `abs(ts_delta(volume/sharesout,1) - group_mean(...,1,market))` 的"平静度"度量。
   我们的 vol 腿一直是 `volume/ts_mean(volume,120)`（拥挤），距离化是不同构的变形。

4. **Slow+Fast Factors 中性化（未测过的保命杠杆）**。
   贴主实证：行业市值中性化质量最好但公共库 corr≈0.8；Slow+Fast 能入库（靠降风险暴露改变 PNL 构成）。
   对照我们：INDUSTRY 中性化试过（corr 转向 w68_b 0.83），**Slow+Fast 从没试过**——
   账号可用性未验证（STATISTICAL/CROWDING 是 400，Slow+Fast 不确定）。若可用，
   对 w96_a/w96_b/w103_g 这批 S3.45-3.55 的判死候选换 Slow+Fast 重模拟，PNL 构成改变可能直接绕开 corr。

5. **贴主讨论区的元教训（与我们实证互相印证）**。
   "优秀的量价因子 PnL 很可能近似（殊途同归）"——解释了为何我们 PV 腿怎么换都撞墙；
   破局方向 = ①量价上叠加其他数据（我们已做：analyst4/fnd2 锚）②不同数理方法处理同一数据
   （条件切换/距离化/拆分——我们没做过，这是本帖最大借鉴）。
