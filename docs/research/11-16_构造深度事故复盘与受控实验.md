### 两种典型形态

**形态 A（ATOMB 11 条，单字段浅变换）**——生成脚本 `_autologs/_gen_atom_blue_1115.py` 注释原文：
> 「每个字段都是 used<=1 的蓝海字段，**表达式只做单字段变换**（ATOM 合规）」

```python
'group_neutralize(ts_zscore({f},60), subindustry)'
'ts_decay_linear(-ts_rank({f},252), 10)'
'ts_quantile(ts_zscore({f},250), 250)'
'group_scale(ts_rank({f},120), sector)'
```

**形态 B（ATOM1115 11 条，多字段但关系被抹掉）**：

```
group_zscore(ts_decay_linear(
    ts_zscore(ts_backfill(analyst_embedding_component_0,20),120)
  + ts_rank(ts_av_diff(analyst_embedding_component_11,20),250)
  - ts_mean(ts_zscore(analyst_embedding_component_100,60),20)
  ,15),subindustry)
```

每个字段**各自独立时序归一化**后，用**任意符号**（+/−，权重全是 1）相加，最后统一 decay + 分组 zscore。

### ★ 病根的准确定位

不是"算子太少"，而是 **复杂用错了地方**：
- 关系（比值/差/条件/相关性）**只出现 3 次**；
- 独立归一化后相加 ⇒ 三个互不相关的信号直接混合 ⇒ **信号互抵 + 幅度失真**（各自 zscore 后量纲都是 N(0,1)，直接相加等于给每个字段 1/3 权重，没有经济含义）。

### ★ 断链点：模板库建好了，却从没进生产

`_grid/atom_complex.py` 的 C1~C6 模板（比值 / 残差化 / 相关性分歧）**11-15 就建好了**，
但全仓 grep 显示它只被三个 probe 脚本调用：

```
_autologs/_atom_probe_sim_1115.py
_autologs/_atom_probe_sim2_1115.py
_autologs/_atom_probe_sim3_1115.py
```

**没有任何生产批次调用它。** 真正上生产的是手写浅构造。
⇒ 这与「`depth_check.py` 上一轮建好却零调用」是**同一个病**：工具建了，没接进路径。

## 三、受控实验：浅构造 vs 深构造（5 数据集 × 2 = 12 条）

**实验设计**：同字段、同设置（USA TOP3000 / decay 20 / MARKET / trunc 0.08），
**只改构造深度**。浅 = 11-15 原式；深 = 逐字段 `ts_av_diff(x,N)/ts_std_dev(x,M)` + 组内求和。

**结果（已落盘 10/12）**：

| 数据集 | 浅构造 S / F / TO | 深构造 S / F / TO | 结论 |
|---|---|---|---|
| option9 | 0.18 / 0.03 / 0.091 | **0.17** / 0.03 / 0.111 | 深挖**没抬** |
| social12 | −0.32 / −0.06 / 0.308 | **−0.11** / −0.01 / 0.520 | 抬了 0.21，但 TO 翻倍，仍全 FAIL |
| mmp | 0.42 / 0.13 / 0.105 | **−0.09** / −0.01 / 0.148 | 深挖**反而更差** |
| anlrev | −0.06 / −0.01 / 0.088 | 未完成 | — |
| aieq / model109 | 未完成 | 未完成 | — |

### ★ 结论一（推翻我 10:50 的说法）

**"挖深"不是充分条件，甚至不是必要条件。**
完整 12 条对照（同字段同设置，只改构造深度）：

| 数据集 | 浅构造 S | 深构造 S | ΔS |
|---|---|---|---|
| option9 | 0.18 | 0.17 | −0.01 |
| social12 | −0.32 | −0.11 | **+0.21** |
| mmp | 0.42 | −0.09 | **−0.51** |
| anlrev | −0.06 | 0.34 | **+0.40** |
| aieq | −0.40 | −0.17 | **+0.23** |
| model109 | 0.16 | −0.45 | **−0.61** |

**3 涨 3 跌，振幅 ±0.6，最好的也只有 0.34** ⇒ **深浅与 S 无关，是随机游走。**
⇒ 李工指出的方向（复杂化 / 挖深）**方向正确**（11-15 那批 18/21 无关系算子是真的浅，
这是必须修的），但**"深挖"本身不产生 alpha**。

### ★ 结论二（决定 S 的是"形态组合"，不是单个变量）

形态对照实验（`_grid/exp_shape_1116.json`，同 option9 字段、同设置）：

| 表达式 | S | 变量 |
|---|---|---|
| `group_rank(ts_av_diff(pcr_oi_10,20)/ts_std_dev(pcr_oi_10,60), subindustry)` | **0.42** | 完整形态（比值+差分+横截面排序） |
| `group_rank(ts_zscore(ts_av_diff(pcr_oi_10,20)/ts_std_dev(pcr_oi_10,60),250), subindustry)` | **0.43** | 多一层时序归一化 ⇒ **无影响** |
| `group_rank(pcr_oi_10/pcr_oi_360, subindustry)` | **−0.09** | 只有比值，**无差分** ⇒ 崩 |

⇒ **三条推论**：
1. **必须有"差分"**（时序变化），光有水平比值没用（X3 = −0.09 vs X1 = 0.42）。
2. **时序归一化不是压制源**（X1 0.42 vs X4 0.43）——我原先的"先归一化毁关系"假设**不成立**。
3. **横截面排序算子的选择是变量**（`group_rank` vs `group_zscore` vs `group_scale`），
   下一批 `EXP_Y1/Y2/Y3` 专门测这个。

⇒ **"挖深"是必要不充分；决定 S 的是形态组合里的关键要素是否齐全（差分 + 关系 + 合适的横截面算子）**，
而**字段本身的信号强度仍然是第一位**（同批 option9 三种形态都只有 0.4 出头，说明这个字段信号本身就弱）。

### ★ 结论三（历史污染底数）

16178 条历史 mined 中 **2899 条（17.9%）被判浅构造**，含大量 1 算子裸件
（`a1_00_r66` 算子=1 层数=0 之类）⇒ 存量候选池需重筛，不能直接当料。
