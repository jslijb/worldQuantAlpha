# Alpha Loop v2 运行手册

## 1. 环境

```bash
source /d/ProgramData/Miniforge3/etc/profile.d/conda.sh
conda activate bigmodel
```

依赖：`requests` / `pytest`（bigmodel 已装）。

## 2. 自检

```bash
python -m alpha_loop.config          # 常量与禁用算子
python -m alpha_loop.auth            # LOGIN_OK
python -m alpha_loop.idea_lib        # idea 数与 PV 占比
python -m pytest alpha_loop/tests -q # 单元测试全绿
```

## 3. 主流程

```bash
python -m alpha_loop.loop --rounds 3 --limit 6            # 全市场轮转
python -m alpha_loop.loop --rounds 1 --limit 2 --market GLB
python -m alpha_loop.loop --dry --rounds 1                # 不真发模拟
```

窗口规则：**北京时间 14:00 前只回测并入队；14:00 后先 drain 队列再回测。**

## 4. 状态文件

| 路径 | 说明 |
|---|---|
| `state/state.db` | units / attempts 全量状态 |
| `state/pending.json` | 跨天待提交队列（原子写） |
| `state/ledger.csv` | 新台账，只追加 |
| `state/fielddb/{region}.json` | 字段缓存（含 region 键） |
| `state/alphas_raw.json` | 历史 alpha 原始列表（24h） |
| `state/raw/{unit_id}.json` | 单条模拟原始响应 |
| `state/verdicts/{alpha_id}.json` | 403 判定真值 |
| `state/knowledge/*.md` | 经验库条目 |
| `state/session.json` | 登录 cookie（避免 captcha） |

## 5. 常用排查

| 现象 | 查什么 |
|---|---|
| `LOGIN_FAIL` | 删 `state/session.json` 重试；若 captcha，等待后再试 |
| 0 条候选 | `fielddb` 是否加载；`match_roles` 是否全 MISS（K-04） |
| 模拟 400 | `state/raw` 无记录时看返回 body；多为算子/字段无权限 |
| 队列不动 | `queue.peek(day_target)`；确认已过 14:00 |
| 提交 403 | `state/verdicts/{id}.json` 的 checks |
| 全部 GATE_FAIL | 先跑 `pytest ... -k gates` 确认门没写反 |

## 6. 停止与恢复

- 停止：`Ctrl+C`；状态全部落盘，重跑自动跳过 `unit_id` 已存在条目。
- 恢复：直接重跑同命令；队列不过期，`day_target` 指向下一个窗口。

## 7. 纪律

- 提交前必过预检（`prod.max`/`self.max` ≤ 0.69）。
- `group_rank` 禁用至 2026-11-23，出现即拒。
- USA 只用历史未用数据集。
- 程序内只自动调表达式/参数；源码缺陷走会话修改 + 回归复验。
