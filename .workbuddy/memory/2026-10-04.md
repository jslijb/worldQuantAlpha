### 深夜续·trade_when 三参数真实口径 + 李工「掩耳盗铃」质疑（结论：不是，但它不避险）
- **三参数 = `trade_when(条件, 条件成立时用的新值, 条件不成立时填的值)`**（`官方_FastExpression操作符清单.md:147,181`）。项目实测（`Research16:101-102`、`01_checks_FAIL全解.md:62,33`、`00_总纲.md:248`）：**第三参数必须是 -1（保持原仓位），用 0 = 平仓，换手反而上去，0914 已翻车**。
- **官方那段（09_intermediate-pack-part-3.md:21）讲的两参数默认行为**：exit condition true → NaN（不交易）；exit false 且 event true → alpha 表达式；两者都 false → 前一日 Alpha。与「传第三参数」是两套口径，讲的时候分开，别混。
- **对「清仓了其实没动=掩耳盗铃」的定性**：-1 压的是**换手率/交易成本**，不是风险；而多空组合里方向风险本来就被中性化减均值抹掉了（单票跌，另一头对冲），真正在亏的是**多空价差漂移**，不是"大盘跌了亏大"。代价 = 信号失效期照样拿着老头寸，收益打折换成本。真要躲风险就别传第三参数（NaN = 真空仓），要低换手就用 -1，**不能又要又要**。

### 深夜续·trade_when 语义纠正（我 1004 讲反了，李工抓出来的）
- **采信口径**（三条交叉证据，已定死）：`trade_when(cond, A, B)` = **cond ? A : B** —— **cond 为 true → 用第二参数 A**；**cond 为 false → 用第三参数 B**。
  1. 硬证据：语法里第三参数存在，就必定有"条件不成立时输出什么"的位置，否则第三参数白摆（这是最硬的推理）。
  2. 官方 example 措辞（`09_intermediate-pack-part-3.md:25`）："implement the Alpha expression based on **only when** the number of stocks traded today is higher than the monthly average" ⇒ 只在 volume>adv20（true）那天让 `-returns` 生效。
  3. 我们自己的实测（`01_checks_FAIL全解.md:62`、`Research16_分析师短期交易思路.md:101-102`）：第三参数 -1（保持）才是有效降换手写法，用 0（平仓）0914 直接翻车、方向反了。
- **官方 line 21 那三段不可采信**：它把 `exit_condition` 和 `event_condition` 当两个条件用（"exit false AND event true → Alpha expression" 在只有一个条件时是空命题），且方向与 example 相反。那段是官方措辞错误/残留，不能当教材、不能背进面试。备考总纲 line 434 本来就写对了（`trade_when(条件, 满足时的值, 否则的值)`），我上一轮按 line 21 讲是讲反了，**认错**。
- **回答李工"true/false 能不能执行同样操作"**：不是割裂，是三个不同出口——true 走第二参数（真信号、当天权重会动）；false 走第三参数（常数占位、不动）；第二参数与第三参数都算不出 NaN 才回落"沿用昨天"。

### 深夜续·trade_when 第三参数 -1 与「权重清空」的语义区别（李工追问：不动和清空不都一样吗）
- **李工的困惑**："-1 说是不动，那和权重清空（NaN/0）从结果看不都是不动吗？"
- **定论（纠正我前一轮的错）**：**清空 ≠ 不动。0 / NaN 是那天平仓，是"动"；-1 才是真不动。**
  - 0 / NaN = 当天目标权重归零 → 引擎把昨天手里这批头寸**全部卖掉/买回清零**，这本身就是一次**全额换手**；第二天信号回来再从零**全额重建**。持仓在"在场↔离场"之间来回切，每次切换都是全额买卖。
  - **实证原话** `docs/research/Research16_分析师短期交易思路.md:93`：「表达式用 `? : NaN`，条件不满足当日直接退出组合。第二天条件满足又回来。**持仓状态在"在场/离场"之间来回切**，每次切换都是全额买卖 —— 这才是 41% 换手的来源。」
  - `-1` = 当天输出不归零，头寸原样留在场上，什么都不用操作。**这才是"保持原仓位"**：`Research16:101` 原话 `trade_when(cond, x, -1)`（条件外保持原仓位**而非清零**）；line 330 复述第三参数 -1 是降换手关键差别，0914 用 0 质量下降、方向反了。
- **为什么必须分清**：turnover 直接进 Fitness 分母（`F = S×√(|R|/max(TO,0.125))`），换手高 = 成本吃收益。选 0/NaN 是自找两次全额买卖，选 -1 是零换手——差别不是"动不动"，是**满仓来回切**。
- **诚实边界（不变）**：-1 内部机制平台未公开（沿用昨日权重 vs 当天给固定占位值），看不到源码；可咬死的只有实测差别（-1 保质量、0 翻车）。不要说死机制，只讲净效果和实测。

### 李工纠：讲"流动性分解式为什么强"老扯远（定稿口径，下次照此答）
- **式子**：`ts_decay_linear(signal,5)*rank(volume*close) + ts_decay_linear(signal,10)*(1-rank(volume*close))`（官方 `04_interpret-results/03_how-pass-sub-universe-test.md:50-55`；李工明确说过**别再扯出处、别扯子池 tip 清单、别扯"别人 4 项"**，只讲这个式子本身为什么强）。
- **定稿四条（以后按这四条讲，一条一句不发散）**：
  1. **量纲守恒的插值**：令 L=rank(volume*close)∈[0,1]，式子 = S₁₀ + L·(S₅−S₁₀)，是 5 天版/10 天版之间随流动性的线性插值，L+(1−L)=1 ⇒ 整体不放大不缩小，不是加杠杆。
  2. **按可执行性分层**：S₅ 尖（保留当日信号）、S₁₀ 钝（抹短期噪声）；活跃票拿尖的吃满、非活跃票拿钝的少挨噪声 = 同一条信号在"交易得动"的那批上用短 decay、"交易不动"的那批上用长 decay。
  3. **子池测试的方向就是它存在的理由**（这条最硬）：官方测 TOP3000 提交要查 TOP1000（更流动）够不够，不够 = 利润主要来自非流动那端（买不到）、OS 会崩；本式把权重落点往流动端收 ⇒ 子池 Sharpe 更容易过线。它是**过闸写法**，不是把母池 Sharpe 拉高的写法。
  4. **换手结构改善**：短 decay 的换手落在活跃票（冲击成本低、便宜），长 decay 落在非活跃票（换手低），混合后比"全池统一 5 天"TO 低、比"全池统一 10 天"信号强 ⇒ 直接对应 F=S×√(|R|/max(TO,0.125)) 能涨。
- **额外必答追问**：为什么用加权插值而不是 `if_else(L>0.5,S₅,S₁₀)` 硬切？——rank(volume*close) 每天重排，硬切在 L≈0.5 处会跳变、权重日间突变推高换手；加权让每只票都是连续混合，日间连续 ⇒ 换手可控。
- **失效边界（别漏）**：母件 TO 已 20%+（om6jXVml 24.71% / WjPRxY7x 22.60%）时短 decay 会继续推高 TO，别用；且我们这边 decay 轴已判死封顶，属试不算稳赚。

### 再订正：流动性分解式「为什么」——官方关键词是 **separately（分开）**，不是"把权重往流动端收"
- **官方原文定位**：`03_how-pass-sub-universe-test.md:50-55`，tip 主句是 "Try **decaying separately** the liquid and non-liquid parts of your signal."，`volume*close` / `cap` 都只是流动性的**代理**（proxy，官方原话）。被替换的旧写法是 `ts_decay_linear(signal, 10)`（:51）。
- **上次口径订正（重要）**：此前答"把权重落点往流动端收"表述不准，会让人以为是整体偏向活跃票。准确说法是——
  - **非液体端 `rank(volume*close)≈0` 那部分，式子里就是 `1×(1-L)·S₁₀` ⇒ 与原式 `ts_decay_linear(signal,10)` 完全等价，一分没动**。
  - 只有液体端（L≈1）被换成 5 天版 ⇒ **液体端加速、非液体端原样**。
- **这才是"例如，而不是"的对比核心（答李工用，定稿）**：
  1. 自然直觉 = 直接把 `10` 改成 `5`。这是**全池一刀切**：液体票快了（子池可能上去），但母池里 TOP3000 的 2000 只非流动票也被强制 5 天 ⇒ 这帮票本就不该高频，信号变尖、噪声进来、母池 Sharpe 更差，且全池 TO 大涨（冷门票滑点贵）。= 拿母池换子池，不划算。
  2. 分开衰减 = **只动该动的那半边**：非液体端保持 10 天（母池收益一分不丢），液体端给 5 天（子池 Sharpe 补回来）⇒ 母池不亏 + 子池过闸。
  3. 系数和恒为 1（L + (1−L)），量纲守恒，不加杠杆；运算符 +2（1 个 rank + 1 个 decay），64 上限内；不引入新数据（volume*close 本就在池，cap 亦可当代理）。
  4. 为何加权不是 `if_else(L>0.5,S₅,S₁₀)` 硬切：rank 每天重排，硬切在 0.5 处临界票日间跳变、权重突变推高 TO；加权日间连续。
- **失效边界**：母件 TO 已 ≥20%（om6jXVml 24.71% / WjPRxY7x 22.60%）别用；池子非流动票占比高时大部分票那块没动、收益有限。

### 流动性分解式「为什么替代后更好」——第三版口径（李工连问三次后的收敛答法）
- **李工点明他问的不是**：不是"多了什么少了什么"、不是"5 和 10 对调"、不是"分票给不同 decay"这几层。他要的是：**凭什么一个加权和能整体顶掉一个单独的 `ts_decay_linear(signal,10)` 且更好。**
- **收敛答法（四点，以后照此答）**：
  1. **替代掉的东西只有一样：把 decay 从「全局常数」变成「票的流动性函数」**。原式 decay=10 对全池一视同仁（1 个自由度）；新式等效 decay = `10 − 5×rank(volume*close)`，每只票一个值、在 5~10 连续（N 个自由度）。**没多数据、没多腿、权重和=1 所以量纲不变**，变的是旋钮的可调粒度与方向。
  2. **轴选对了**：自由度沿"流动性"这根真实维度铺开，而这根轴正是子池闸口在考的那条（子池=TOP1000=活跃端）。⇒ 冷门票那块（L≈0）新式 = 100% 的 10 天版 = 与原式逐点相同，**母池 Sharpe 一点不丢**；活跃票（L≈1）拿到 5 天版，子池端才有收益。全池统一改成 5 天做不到这点（冷门票跟着白挨噪声 + TO 大涨）。
  3. **多尺度 = 分散**：同一 signal 的 5 天版与 10 天版抓的是两段不高度相关的 PnL（corr<1），加权拼 ⇒ Sharpe 高于单押一个尺度。原式把全部仓位押在 10 天这一尺上。
  4. **成本更低**：混合后的 TO 低于"全池统一 5 天"（短 decay 那份换手落在活跃票、滑点便宜；长 decay 那份落在冷门票、换手本就低）。
- **不可泛化（必说）**：它只在"子池过不去"这个毛病上是药方，不是通用增强；子池本来过了就没必要，母件 TO≥20% 别用（活跃端再加速把 TO 顶上去）。
