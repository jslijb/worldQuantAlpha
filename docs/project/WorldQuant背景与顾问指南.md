## 一、一句话总结

WorldQuant（世坤投资）是一家 2007 年成立的量化资管公司，AUM 近 100 亿美元。BRAIN Consultant 是开放给所有人的兼职 Alpha 挖掘岗位，按提交的 Alpha 数量、质量和"级别（value factor）"获取报酬。

## 三、什么是 BRAIN Consultant（研究顾问）

- 通俗讲是一个开放给所有人的**兼职岗位**，通过 Python 脚本或平台界面操作。
- 利用平台提供的海量 **15 万+ 数据、算力和 API 框架**进行数据特征（Alpha）挖掘。
- 报酬取决于提交的 Alpha 数量、质量和个人在平台的"等级"。
- 成为顾问需签署**顾问协议合同**，按平台固定付款周期获取报酬。
- 顾问每天可在平台内看到当天收入；收入多少取决于"级别（value factor）"和活跃程度；**没有提交就没有收入**。
- 前三个月为"试用期"，收入较少；三个月后根据表现提升"级别（value factor）"，收入可有几倍甚至几十倍提升。每人方差较大，从几百元到几万元都有。
- ⚠️ **利益冲突**：当前在金融机构或金融科技等公司任职者，可能因利益冲突问题无法成为兼职顾问。

## 四、用户权限 vs 顾问权限

| 维度 | 用户权限（新手试用） | 顾问权限 |
|---|---|---|
| 导航栏颜色 | 蓝色 | 绿色 |
| 数据 | 远不如顾问 | 完整 |
| 地区 | 受限 | 完整 |
| 功能 | 受限 | 完整 |
| 算力 | 受限 | 完整 |
| **同时回测 Alpha 数量** | **最多 3 个** | **最多 10 个** |

> 注：用户同时只能回测 3 个 Alpha 因子，研究顾问可同时回测 10 个。

## 四-B. 账号 Region 选择规则（易踩坑）

- **选所在地，不是国籍**：region 填当前合法所在地。例如持大陆护照但在香港读书/工作（有签证），应填香港，不是大陆。
- **香港区域排队更快**：大陆区从上课到成为 consultant 可能 1-2 个月甚至更久；香港排队的人少，更快。
- **不能乱填**：内地人填香港，背调通不过，账号白忙活。
- **填香港的硬性条件**：合法在港证明（工作签证 / 学生签证 / 香港身份证）+ 香港本地银行卡（任何 region 都要当地银行卡才能打款）。
- **尽早修改 region**：越晚改（尤其收到顾问邀请后突然改），账号被锁定风险越大。
- **银行卡一致性**：问卷填的姓名必须与绑定银行卡姓名一致，否则账号立即关闭；不能用家人卡代收。
- **税**：香港税率可能比国内低（如约 3%）；各地税率不同。

> 更详细讲解见 `BRAIN_零基础学量化第一课_新手入门.md`（文档 25）。

## 五、如何成为顾问

决定账户能否升级为顾问，取决于你的 **Challenge Score**。

### 自动邀请路径

- 达到 **10,000 分（Gold Level）** 后的第二天，通常可获得系统自动邀请。
- 注意平台有系统风控，**并非所有用户都会收到邀请**，仍需认真学习。

### 国区（中国）额外要求

- 除达到 10,000 分外，国区申请者需继续提交到 **20 个 Alpha**。
- 需通过 **Alpha 研究能力测试题**（均为"零基础学量化"讲座中的基础知识）。
- 通过后才能获得顾问资格。

### Challenge Score 查询入口

- 路径：`Competitions` → `Challenge` → 点击进入查看自己的 Challenge Score。

## 六、Challenge Score 计分规则与常见坑点（敲黑板）

| 规则 | 说明 |
|---|---|
| **每日上限 2000 分** | 不管提交多少，每天最多 2000 分 |
| **T+1 更新** | 分数非实时更新，约在北京时间下午 2-3 点更新 |
| **1 个 Alpha ≈ 1500-2000 分** | 通常 2 个 Alpha 可确保拿满 2000 分 |
| **美东时间口径** | 平台全球统一采用美东时间；北京时间 19 号下午 + 20 号上午 = 美东 19 号 |

### 时间换算速记

- 北京时间 = 美东时间 + 12 小时（夏令时）
- 北京 19 号 15:00 之后 = 美东 19 号 03:00（仍属 19 号）
- 北京 20 号 00:00-11:59 = 美东 19 号 12:00-23:59（仍属 19 号）

## 七、考试速查卡

### 公司背景

- 2007 年成立，总部美国格林威治
- 中国分部：北京、上海
- AUM 近 100 亿美元

### 顾问路径

- Challenge Score ≥ 10,000（Gold）→ 次日自动邀请（有风控）
- 国区额外：累计 20 个 Alpha + 通过 Alpha 研究能力测试
- 签署顾问协议，按 value factor 和活跃度获酬

### Challenge Score 坑点

- 每日上限 2000
- T+1，北京时间下午 2-3 点更新
- 美东时间口径，别按北京时间算天数

---

## 八、易错点

1. **按北京时间算提交天数**：平台用美东时间，北京 20 号上午仍算美东 19 号。
2. **以为分数实时更新**：T+1，北京时间下午 2-3 点才更新。
3. **以为提交越多分越多**：每日上限 2000，2 个高质量 Alpha 即可拿满。
4. **忽略利益冲突**：在金融机构/金融科技任职可能无法做兼职顾问。
5. **国区只看分数**：国区还需 20 个 Alpha + 能力测试。
6. **以为满分必邀请**：系统风控可能不发邀请。
