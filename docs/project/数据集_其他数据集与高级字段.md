## 一、一句话总结

除价量/基本面/分析师/情绪/新闻/关系 6 大类主数据集外，BRAIN 还有 **26 个"其他"数据集家族**（模型类、信用类、内幕类、期权类、系统性风险类等），以及只能在 **Python 模式**下使用的**向量数据**（高级关系数据 rlv_*、高级预估数据 etv_*）。

## 三、Ravenpack 新闻数据（详解）

Ravenpack 新闻数据集提供不同情绪评分，范围 **-1.00 到 1.00**。

### 三类核心评分

| 评分 | 全称 | 说明 |
|---|---|---|
| **ESS** | Event Sentiment Score | 探测 6,700+ 商业/经济/地缘政治事件类别的情绪；基于实体及时效性动态分配分数 |
| **CSS** | Composite Sentiment Score | 通过情绪词短语匹配，对约 100 只大盘股 tick data 经验建模确定强度 |
| **NIP** | News Impact Projections | 快讯发布后两小时内对市场的影响程度（相对波动率高低预测） |

### 主题后缀（部分）

`mna`(并购)、`ratings`(分析师评级)、`assets`(资产)、`business`(业务)、`credit`(信用)、`credit_ratings`(信用评级)、`dividends`(股息)、`earnings`(收益)、`equity`(股权行动)、`insider`(内幕交易)、`investor`(投资者关系)、`labor`(劳工)、`legal`(法律)、`marketing`(营销)、`partner`(合作)、`ptg`(目标价)、`product`(产品)、`revenue`(收入)、`society`(社会)、`price`(股价)、`technical`(技术分析)

字段命名示例：`rp_css_mna`（并购新闻综合情绪得分）、`rp_ess_ratings`（评级相关事件情绪得分）、`rp_nip_earnings`（盈利相关新闻影响预测）。

## 四、向量数据（Vector Data，Python 模式专用）

### 关键属性

- 这些字段**只能在 Python 模式**下构建 Alpha（Expression 模式不可用）。
- 字段采用 **Offset / Vector 形式**，非 Matrix。
- `*_offset` 字段通过 `[di][ii]` 访问，返回元组 `(start, num)`：start 是向量数据起始位置，num 是条目数量。
- 非 offset 字段通过 `<field_name>[off]` 访问，off 应在 `[start, start+num)` 之间。
- `*_id` 字段标识符指 `alpha.shape[0]` 中的 ii。

### 高级关系数据（Advanced Relationship Data）

适用于 Customers(cust)、Competitors(comp)、Strategic Partners(part) 及 Relationships(rel) 类别。

| 字段 | 描述 |
|---|---|
| `rlv_cust_offset` / `rlv_cust_id` / `rlv_cust_rev` | 客户相关：偏移量 / 标识符 / 来自客户的收入占比(0-100) |
| `rlv_comp_offset` / `rlv_comp_id` | 竞争对手相关：偏移量 / 标识符 |
| `rlv_rel_offset` / `rlv_rel_id` / `rlv_rel_overlap` / `rlv_rel_focus` | 关系相关：偏移量 / 标识符 / 共同行业数 / 共同专注行业数 |
| `rlv_part_offset` / `rlv_part_id` / `rlv_part_type` | 合作伙伴相关：偏移量 / 标识符 / 关系类型(0-13: DISTRIB/EINVEST/LICENIN/MANUFAC/MARKTNG 等) |

### 高级预估数据（Advanced Estimate Data）

Python 模式下可用的高级预估数据：29 个数据值（eps、sales 等）× 14 个字段（offset、estimate、ann_date 等）= **406 个数据字段**。

关键字段：`offset`(偏移量)、`ann_date`(公告日期 YYYYMMDD)、`broker`(经纪商ID)、`cons_date`(一致预期日期)、`cons_inc`(纳入/排除 '0'/'1')、`curr`(货币，currencylx[curr] 返回 "USD")、`est_dir`(方向 U/D/F/N：上调/下调/持平/新预测)、`estimate`(估计值)、`fisc_date`(财期结束日)、`prev_est`(先前预估)、`rel_date`(期间相对日期 [-15,+15])、`resr_date`(研究日期)、`analyst`(分析师ID) 等。

数据值示例：dvps、eps、sales、bvps、capex、cff、cfi、cfo、ebit、ebitda、epsa、epsr、fcf、wcap、grsinc、ntdebt、ntprftadj、ntprft、ptp、ptpr、rdexp、sgna、sh_eq、tbvps、totasset、totgdwl 等。

> 注意：同一 DataName 的字段共享 offset；无效数据可能返回 NAN、-1、-2147483648 等，Alpha 需处理并过滤。

### 向量数据 Alpha 示例（Python 模式）

```python
# Example 1: 客户收益率（rel_ret_cust 实现）
cust_offset = dr.GetData('rlv_cust_offset')
cust_est = dr.GetData('rlv_cust_id')
ret = dr.GetData("returns")
def Generate(di, alpha):
    for ii in xrange(len(alpha)):
        start, num = cust_offset[di - delay][ii]
        if (start >= 0 and num > 0):
            total_res = 0
            for off in xrange(start, start + num):
                if (cust_est[off] >= 0 and np.isnan(ret[di - delay][cust_est[off]]) == False):
                    total_res = total_res + ret[di - delay][cust_est[off]]
            alpha[ii] = total_res
```

```python
# Example 3: 竞争对手月度收益（用 cap 月度收益，对拆股稳健）
comp_offset = dr.GetData('rlv_comp_offset')
comp_est = dr.GetData('rlv_comp_id')
vec_cap = dr.GetData("cap")
def Generate(di, alpha):
    for ii in xrange(len(alpha)):
        start, num = comp_offset[di - delay][ii]
        if (start >= 0 and num > 0):
            total_res = 0
            for off in xrange(start, start + num):
                local_res = -1 + vec_cap[di - delay][comp_est[off]] / vec_cap[di - delay - 21][comp_est[off]]
                total_res = total_res + local_res
            alpha[ii] = total_res
```

```python
# 高级预估数据示例：销售额预测
sales_offset = dr.GetData('etv_sales_offset')
sales_est = dr.GetData('etv_sales_estimate')
def Generate(di, alpha):
    for ii in xrange(len(alpha)):
        start, num = sales_offset[di][ii]
        if (start >= 0 and num > 0):
            total_sales_est = 0
            for off in xrange(start, start + num):
                total_sales_est = total_sales_est + sales_est[off]
            alpha[ii] = total_sales_est
```

## 五、考试速查卡

### 其他数据集（26 家族）

- 模型类最多（基本面评分、SmartRatios、EPS/收入/EBITDA 估计、价格动量、信用/风险等）
- Ravenpack 新闻：ESS / CSS / NIP 三类评分，主题后缀丰富（rp_css_*、rp_ess_*、rp_nip_*）
- 另类：内幕（Insider）、空头持仓（Short Interest）、期权分析（Options）、系统性风险、波动率

### 向量数据（Python 模式）

- 仅 Python 模式可用，Offset/Vector 形式
- 高级关系：`rlv_cust_*` / `rlv_comp_*` / `rlv_rel_*` / `rlv_part_*`
- 高级预估：`etv_<DataName>_offset` + `etv_<DataName>_estimate` 等（406 字段）
- 访问：`*_offset[di][ii]` → `(start, num)`；非 offset 字段 `[off]` 在 `[start, start+num)`
