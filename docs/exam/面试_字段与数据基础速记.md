# 面试 · 字段与数据基础速记

> 口径来源：Learn 官方文档 `05_understanding-data`（已归档于 `docs/study/learn/docs/05_understanding-data/`）+ 你自己的挖矿实战（36 条 Amihud 流动性 Alpha + fundamental6 字段）。
> 用途：面试被问"字段/数据"类问题时照着答，不考英文翻译，考概念和运用。

---

## 一、先稳住：面试官怎么问"字段"

不会让你翻译英文字段名。高频就三类：
1. **字段有哪几种类型？**（必问，Matrix / Vector / Group）
2. **你怎么选、怎么评估一个字段？**（覆盖率 / 拥挤度 / 新鲜度）
3. **某类数据代表什么经济含义？**（基本面 / 价量 / 分析师 / 另类）

你已有的实战底子（直接拿来当答案）：
- 提交过 36 条 **Amihud 流动性** Alpha → 你说"我用 volume 类字段做过流动性因子"
- 主力用 **fundamental6** 字段（cashflow_op / enterprise_value / fnd6_xrent）→ 你说"我用公司基本面字段做过价值因子"
- 踩过相关性墙 → 你说"我理解数据拥挤的概念，会主动避开被大量 Alpha 使用的字段"

## 二、字段三大类型（必背，几乎必问）

| 类型 | 含义 | 例子 | 关键约束 |
|---|---|---|---|
| **Matrix** | 截面数据：每天全市场每只股票一个值 | `price` `volume` `returns` `close` | 直接进表达式 |
| **Vector** | 时序数据：单只股票自己的历史序列 | 基本面 `fnd6_*`、分析师预期 `analyst4_*` | **必须 `vec_avg` / `vec_sum` 转成 Matrix 才能用** |
| **Group** | 分类标签（不参与计算，只做分组键） | `sector` `industry` `subindustry` `market` | 只用于 `group_rank` / `group_neutralize` 的分组参数 |

**面试加分点（踩坑经验）**：Vector 字段不转就裸进表达式 = 把"时间序列"当"截面值"用，结果必然错；必须用 `vec_*` 算子把它压成每天一个截面值。

## 三、数据家族与经济含义（被问"这字段啥意思"就这么答）

| 家族 | 经济含义 | 典型字段 | 你用过？ |
|---|---|---|---|
| **基本面 fundamental** | 公司财务：盈利 / 现金流 / 负债 / 营收 | `cashflow_op` `enterprise_value` `fnd6_xrent` | ✅ 主力 |
| **价量 market / volume** | 交易行为：价格 / 成交量 / 收益 | `returns` `volume` `vwap` `adv` | ✅ Amihud 流动性 |
| **分析师 analyst** | 卖方预期 / 评级 | `analyst4_*` 评级值 | ⚠️ 全是 Vector，要先 `vec_avg` |
| **另类 alternative** | 新闻 / 社媒 / 期权情绪 | `news` `social` `option` | ⚠️ 实测易空值，谨慎 |

## 四、怎么选 / 评估一个字段（讲这套，就是 6 tips 浓缩）

1. **Instrument Coverage 高**——越多股票有数据越好，低于 70% 谨慎
2. **Date Coverage 满**——每天都有更新
3. **低拥挤**——Alphas 数少的字段 = 没人用的金矿，撞相关性概率低
4. **新鲜度**——更新频率高（季度 vs 日频，看假设需要）
5. **经济逻辑成立**——字段确实衡量你假设里的那个概念
6. **避开冷到无数据的字段**——平台不报错但出空值，等于白做

一句话：**覆盖率要高、拥挤度要低、经济含义要对。**

## 五、被点名问某字段，现成话术（挑你会用的讲）

- `ebit / cap`（盈利收益率）→ 低估因子，盈利相对市值便宜
- `cashflow_op / enterprise_value` → 现金流相对企业价值，价值因子
- `fnd6_xrent` → 基本面里的租金类字段，你的强腿之一
- `returns` → 日收益率，做动量 / 反转
- `volume` → 成交量，流动性
- `abs(returns) / volume`（Amihud 非流动性）→ 你 36 条全用它，价跌量小=非流动性高

## 六、数据类高频面试题自测（对着讲一遍就过关）

1. Matrix / Vector / Group 区别？Vector 为什么必须 `vec_*`？
2. 你怎么判断一个字段值不值得用？（覆盖率 / 拥挤度 / 新鲜度）
3. 基本面数据和价量数据，在构建 Alpha 上有什么区别？
4. 什么是"拥挤字段"，怎么避开？
5. 分析师数据是 Vector，怎么处理才能进表达式？
6. 一个字段覆盖率低但你的假设很好，用不用？为什么？
7. 你实际用过哪些数据家族？分别做出过什么类型的因子？

## 七、给你的定心丸

你不是"没用过平台"——你是用**脚本流水线**用的，所以点网页按钮不熟，但底下的数据概念、字段类型、拥挤度判断你都实操过。面试把上面六题讲顺，数据这块就是你的强项而不是短板。
