# Learn 学习材料 — 归档索引

> **用途**：李工备考 BRAIN 研究顾问面试，Learn 材料本地化归档的**总入口**。
> **原则**：本地组织**对齐官方结构**——文档一页一文件（按官方课程目录分文件夹），视频一个课程组合并成一个文件。
> **创建** 2026-09-15｜**最近更新** 2026-09-15（官方 documentation 全部 29 页已自动抓完，手工稿已归档）

## 〇、平台 Learn 是**两套独立内容**（先搞清楚这个）

| | **文档**（documentation） | **视频课程**（courses） |
|---|---|---|
| 页面路径 | `/learn/documentation/{page_id}` | `/learn/courses/{course_id}/{video_id}` |
| 目录接口 | `GET /tutorials`（课程 → 页面） | `GET /video-courses`（课程组 → 视频） |
| 正文接口 | `GET /tutorial-pages/{page_id}` | 视频自带的 `transcript` 字段 |
| 规模 | **7 个课程 / 29 页** | **16 个课程组 / 69 个视频 / 50 带字幕** |
| 内容 | 文字 + 表格 + 图片 + 公式 + 示例表达式 + 内嵌视频 | 视频 + **官方英文字幕** |
| 本地落法 | `docs/<NN>_<课程id>/<MM>_<页面id>.md` | `视频合集_课程名.md`（**一组一文件**） |
| 抓取脚本 | `src/tools/fetch_learn_docs.py` | `src/tools/fetch_learn_video.py` |
| **当前状态** | ✅ **29/29 全部归档** | 1/16 组已译（`introduction-alphas`） |

> ⚠️ 两套内容**有重叠但不重复**：文档页里的「内嵌视频」往往就是 courses 里的某个视频，
> 可用 `uid`（YouTube id）在 `video_courses.json` 里反查并取字幕。
> 例：`about-brain-platform` 内嵌的 `A3RNoYAz_9U` = `introduction-quantitative-finance/creating-quant-alpha`（字幕 4994 字符）。

## 四、命名与放置规则

| 内容 | 命名 | 说明 |
|---|---|---|
| 文档页 | `docs/<NN>_<课程id>/<MM>_<页面id>.md` | `NN` = 官方课程 sequence；`MM` = 该课程内页序；**标题用官方标题原文** |
| 配图 | `docs/images/<页面id>/<序号>_<原始文件名>` | 序号保证同页唯一，原名保留可追溯 |
| 视频课程合集 | `视频合集_课程名.md` | **一个课程组一个文件** |
| 手工稿 | `_手稿存档/` | 官方原文到位后一律移入，不再新增 |

**视频合集的内部结构**（由 `merge_video_notes.py` 生成）：合集信息 → 目录 → 逐视频（中文译文 + 英文原文）→ 附录 A 字幕勘误汇总 → 附录 B 术语总表（跨视频去重）→ 附录 C 面试考点汇总。

## 五、抓取工具

| 脚本 | 用途 | 用法 |
|---|---|---|
| `src/tools/fetch_learn_docs.py` | 抓**文档页**（文字/表格/图片/公式/示例表达式/内嵌视频链接） | `tree` 目录树｜`page <id> --out <md>` 单页｜**`all` 全量抓取**（幂等，可重跑） |
| `src/tools/fetch_learn_video.py` | 抓**视频课程**元数据与官方英文字幕 | 直接运行 → `_autologs/learn_video/video_courses.json` |
| `src/tools/merge_video_notes.py` | 同组多个视频译文**合并**成一份合集 | `--title … --course-id … --out … 视频*.md` |

**`all` 子命令**：`python src/tools/fetch_learn_docs.py all`
- 一次抓完 29 页，按官方课程结构落盘，并生成 `docs/README_官方文档结构.md`
- **幂等**：图片已存在则跳过，可随时重跑（平台更新内容后重跑即同步）
- 文档页内嵌的视频会**自动反查课程库**，有官方字幕就在页首挂一行提示

**处理过的块类型**（接口 `content` 数组）：

| 块类型 | 数量 | 转成 |
|---|---|---|
| `TEXT` | 238 | Markdown（链接/加粗/列表/内嵌图） |
| `HEADING` | 123 | `##`~`######`（页标题占 H1，层级 +1） |
| `IMAGE` | 81 | 下载到本地 + `![]()` 引用 |
| `SIMULATION_EXAMPLE` | 24 | ``` 表达式代码块 + 12 项模拟设置对照表 |
| `EQUATION` | 12 | `$$ … $$`（LaTeX **原样保留**） |
| `TABLE` | 6 | Markdown 表格 |

> 💡 **遇到 YouTube 源不必折腾**：`source=YouTube` 只表示视频托管在 YouTube，
> **字幕（`transcript` 字段）由 BRAIN 接口一并返回**，取字幕**不需要访问 YouTube**。
> 文档页里嵌的 YouTube 视频同理——拿 `uid` 反查 `video_courses.json` 即可。
