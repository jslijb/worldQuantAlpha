## 三、11-15 那 12 条新数据集 ATOM 批为什么全灭（S 0.11~0.67）——**构造方式错了，不是数据集不行**

落盘代码原文（`data/alpha_quality_analysis/mined/ATOM1115_07_fund23_payables.json`）：

```
group_zscore(ts_decay_linear(ts_rank(accounts_payable_nontrade,250) - ts_zscore(accumulated_depreciation_2,250) + ts_rank(accounts_receivable_total_5,...)))
```

三个**互不相关**的字段各自 zscore/rank 后等权相加 = 字段堆砌，信号互抵。
12 条全灭分布：S −0.40 ~ 0.67，FAIL 集中在 LOW_SHARPE / LOW_FITNESS / LOW_2Y_SHARPE。

**对照 QPK3n9Zw**：同族字段做**比值**（call_90/put_90）和**期限差**（call_90 − call_30），有机制。

> **判据（写死）：没有经济机制的字段堆砌一律当噪声弃掉。每条候选必须能用一句话说清"在赌什么"，说不清就不许进批。**

## 四、真 bug：字段归属是 region 相关的，本地 judge 会串味

平台缓存实测（`data/alpha_quality_analysis/all_fields_*.json`）：

| 字段 | USA 缓存 | EUR 缓存 |
|---|---|---|
| `cashflow_op` / `enterprise_value` | **fundamental6** | **fundamental23** |

`src/core/atom.py:_load_field_map()` 用 `setdefault` 把各市场缓存合并成一锅，谁先加载谁定 —— glob 顺序让 EUR 缓存压过 USA，**判出的数据集标签会错**（ATOM 的"单集/多集"结论多数仍对，标签不可信）。

AGENTS.md §1 原文要求"字段归属以平台 /data-fields 返回的官方 dataset.id 为准，归属不明的先查 API 再判，禁止猜"。
**⇒ 修法（待批）：判定改按市场分桶，字段映射表带 region 维度。**

## 六、机制型字段族清单（字段来自平台缓存实测，数据集归属以对应市场缓存为准）

| 族 | 市场 | 字段数 | 天然配对（比值/期限结构） | 机制一句话 |
|---|---|---|---|---|
| **option8** | USA | 64 | `implied_volatility_call_90/implied_volatility_put_90-1`；`implied_volatility_call_90 - implied_volatility_call_30`；`historical_volatility_90` vs `implied_volatility_call_90`（隐含-已实现溢价） | 波动率偏斜/期限结构定价了不同的杠杆与恐慌需求 |
| **fundamental6** | USA 886 / GLB 197 | | `cashflow_op/enterprise_value`；`capex/enterprise_value`；`fnd6_int_*`/assets | 现金流与资本开支的相对强度→资产定价效率 |
| **fundamental23** | USA 49 / GLB 1455 / EUR 213 | | `accounts_receivable_total_5 / accounts_payable_nontrade`；`accounts_current_assets_equity` vs `accounts_total_current_assets` | 营运资本结构变化→经营质量 |
| **model109** | USA 47 / GLB 112 | | `accruals_percentage_earnings` vs `analyst_cfps_revision_fy1_1m`；`analyst_book_value_per_share_revision_3m` vs `analyst_dividend_per_share_diffusion_1m` | 应计质量与分析师修正的背离→预期修正空间 |
| **model51** | USA 16 | | `beta_last_30_days_spy` vs `beta_last_360_days_spy`；`unsystematic_risk_last_30_days` vs `unsystematic_risk_last_360_days`；`correlation_last_30_days_spy` vs `correlation_last_360_days_spy` | 风险特征期限结构变化→市场重新定价该股 |
| **model26** | GLB 154 | | `analysts_count_revising_up_quarter1_earnings_7d` vs `..._down_...`；`avg_change_analyst_recommendation_30d` | 修正方向与广度的比值→共识漂移速度 |
| **news18** | USA 121 | | `event_sentiment_score` vs `event_novelty_score_2`；`equity_sentiment_score` vs `composite_sentiment_score_2` | 事件情绪强度与信息新鲜度分离→未被充分定价的事件 |

**用法**：每族先做**单字段裸扫描**（1 字段 + 1 时序算子 + 1 横截面算子），把有信号的两个天然配对字段再组合成比值/期限差；**禁止**三个不相关字段相加。
