# Learn 学习材料 — 归档索引

> **用途**：李工按批次提供 BRAIN 平台 Learn 内容，此处维护 **官方结构 ↔ 本地归档** 的对照与归档状态。
> **原则**：本地文件组织**对齐官方结构**——文档一页一个文件，视频**一个课程组合并成一个文件**，避免文件数失控。
> **创建** 2026-09-15｜**最近更新** 2026-09-15

## 〇、平台 Learn 的两套内容（先搞清楚这个）

平台 Learn 页面上看起来是一大片，实际是**两套相互独立的内容**，取数接口也不同：

| | **文档**（documentation） | **视频课程**（courses） |
|---|---|---|
| 页面路径 | `/learn/documentation/{page_id}` | `/learn/courses/{course_id}/{video_id}` |
| 目录接口 | `GET /tutorials`（课程 → 页面） | `GET /video-courses`（课程组 → 视频） |
| 正文接口 | `GET /tutorial-pages/{page_id}` | 视频自带的 `transcript` 字段 |
| 规模 | **7 个课程 / 29 页** | **16 个课程组 / 69 个视频** |
| 内容 | 文字 + 表格 + 图片 + 内嵌视频 | 视频 + **官方英文字幕** |
| 本地落法 | `NN_标题.md`（一页一文件） | `视频合集_课程名.md`（**一组一文件**） |
| 抓取脚本 | `src/tools/fetch_learn_docs.py` | `src/tools/fetch_learn_video.py` |

> ⚠️ 两套内容**有重叠但不重复**：文档页里的"内嵌视频"往往就是 courses 里的某个视频，
> 可用 `uid`（YouTube id）在 `video_courses.json` 里反查并取字幕。
> 例：`about-brain-platform` 内嵌的 `A3RNoYAz_9U` = `introduction-quantitative-finance/creating-quant-alpha`（字幕 4994 字符）。

## 四、命名与放置规则

| 内容 | 命名 | 说明 |
|---|---|---|
| 文档页 | `NN_标题.md` | `NN` 为归档顺序号；标题取官方标题（必要时加官方 id 便于回溯） |
| 视频课程 | `视频合集_课程名.md` | **一个课程组一个文件**，内部含该组全部视频的中英对照 |
| 配图 | `images/{page_id}/{page_id}_NN.png` | 由抓取脚本自动下载、按序号命名 |
| 外链缓存 | `refs/引用链接缓存.md` | 文末引用链接的要点摘要（**不是**全文镜像） |

**视频合集的内部结构**（由 `merge_video_notes.py` 生成）：合集信息 → 目录 → 逐视频（中文译文 + 英文原文）→ 附录 A 字幕勘误汇总 → 附录 B 术语总表（跨视频去重）→ 附录 C 面试考点汇总。

## 五、抓取工具

| 脚本 | 用途 | 用法 |
|---|---|---|
| `src/tools/fetch_learn_docs.py` | 抓**文档页**（文字/表格/图片/内嵌视频链接） | `tree` 打印官方目录树；`page <page_id> --out <md路径>` 抓单页 |
| `src/tools/fetch_learn_video.py` | 抓**视频课程**元数据与官方英文字幕 | 直接运行，输出 `_autologs/learn_video/video_courses.json` |
| `src/tools/merge_video_notes.py` | 把同组多个视频译文**合并**成一份合集 | `--title … --course-id … --out … 视频*.md` |

原始证据（未加工 JSON）留档：`_autologs/learn_docs/`、`_autologs/learn_video/`。

> 💡 **遇到 YouTube 源不必折腾**：`source=YouTube` 只表示视频托管在 YouTube，
> **字幕（`transcript` 字段）由 BRAIN 接口一并返回**，取字幕**不需要访问 YouTube**。
> 文档页里嵌的 YouTube 视频同理——拿 `uid` 反查 `video_courses.json` 即可。
