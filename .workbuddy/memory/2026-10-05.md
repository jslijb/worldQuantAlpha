## 算子辨析：days_from_last_change vs last_diff_value（李工问）

- **来源边界（记牢）**：这两个算子的**官方英文原文本仓没核到**——`docs/study/learn/` 缓存里没有算子清单页，`docs/project/官方_FastExpression操作符清单.md` 是 operators.pdf 的 **OCR 中文译本**（:93 / :96）。平台可用与否只核到 `_autologs/ops.txt` 白名单里两个都在。以后引用只能说"官方中文归档译"，不能说"官方原文"。
- **核心区别（一句话稳态口径）**：`days_from_last_change(x)` 返回**天数**（时间量），距上次变化过了几天，**无窗口参数**（等于无限回溯）；`last_diff_value(x, d)` 返回**数值**（与原字段同量纲），过去 d 天里离现在最近那个跟当前值不同的值，**必须给 d**。一个是"变了多久"，一个是"上次是多少"，不能互相替代。
- **用法落点（本仓实测）**：候选池 1098 条里 `last_diff_value` 用 **0 条**、只有 `days_from_last_change` 用 1 条；台账 176 条已提交 **0 条**，spec 文件里 0930 两条（ahGAP / x1kG）都是同一个 `gap_ZY0vkmbn`。该条表达式：`trade_when(days_from_last_change(eps) < 20, ... , -1)`，含义 = EPS 超过 20 天没更新就当日不出信号（数据新鲜度门）；实测 S 2.34 / F 1.64 / SF **3.98**（差 0.02 没到 S+F≥4.0 硬门）/ tS 2.56 / TO 17.22% / fails 空。**说明它当门控是我们在用的唯一范式，别指望 last_diff_value 有现成案例。**
- **未核到的细节（别背死数）**：① 计数含不含当天、从 0 还是 1 起数，官方归档没写死；② `last_diff_value` 在 d 天内一直没变化（值恒等于当前值）时返回什么，官方没写（推测 NaN 但未核）；③ `days_from_last_change` 无 d 参数 ⇒ 高频字段天天 0/1 没区分度，只对低频字段（EPS/财报/授权回购额）有意义。
- **易答串点**：同类返回"距今几天"的还有 `ts_arg_max(x,d)` / `ts_arg_min(x,d)`，但触发基准不同——days_from_last_change 看**变点**（值跟昨天不一样），ts_arg_max 看**极值点**（过去 d 天最高/最低那天）。两者都能当门控，判据别混。

### group_mean（官方一手原文到手）+ 订正 OCR 归档漏译「调和」
- **官方定义**：`group_mean(x, weight, group)` = 按 group 分组，每组算 x 的**调和平均**（harmonic mean），weight 可选。官方示例：某行业三只股票 P/E=10/15/20 ⇒ `3 / (1/10+1/15+1/20) ≈ 13.85`，**组内所有股票当天都被赋成这个组均值**（横截面填值，跟 group_rank 同一类动作）。
- **订正（重要，防再答错）**：`docs/project/官方_FastExpression操作符清单.md:157` 此前 OCR 成"（加权）均值"、**漏了"调和"二字**；`docs/exam/操作符中文速查表.md:124` 同步误记。两行已按平台一手原文订正为「**调和**平均数」。⇒ **教训：这张表是 operators.pdf OCR 译本，凡是带"均值/平均"的算子行都要回头核是不是漏译了"调和"（调和平均与算术平均差得出来：上例 13.85 vs 15）**。
- **调和平均口径（答复用）**：`H = n ÷ Σ(1/xᵢ)`，等价于"**按 1/x 加权的算术平均**"（可验证：令 wᵢ=(1/xᵢ)/Σ(1/x)，则 Σwᵢxᵢ = n/Σ(1/xᵢ)）⇒ **值越小，权重越大**。带 weight 时 `H = Σw ÷ Σ(w/x)`（官方示例未给带 weight 的例子，此式为按标准定义外推，未核实）。**只对齐正值**；P/E 为负（亏损股）时 1/x 变号，结果翻车。
- **别跟 group_neutralize 混**：mean = **换成**组均值（填值）；neutralize = **减掉**组均值（去均值化，等价面板 Neutralization）。一个值变成一个常数，一个变成偏离量。
