# 黄金骨架库（历史实证提炼）

> 来源：1098 条历史模拟记录中最强的配方结构
> 用途：新因子设计的起点模板——**不要从零想，从骨架改**

---

## 一、为什么用骨架而不是从零设计

历史数据显示：**同一字段组合签名（骨架）会被反复复用**，且复用后的全过率远比随机组合高。

最有价值的证据：

| 字段组合签名 | 出现次数 | 三关全过 | 全过率 |
|---|---|---|---|
| `cashflow_op, enterprise_value, fnd6_xrent` | 84 | 80 | **95.2%** |
| `cashflow_op, enterprise_value, fnd6_newqv1300_cimiiq, fnd6_xrent` | 23 | 22 | **95.7%** |
| `annual_intangible…, authorized_stock_buyback…, cashflow_op, enterprise_value` | 42 | 35 | 83.3% |
| `anl4_…sga_median, authorized_stock_buyback…, cashflow_op, enterprise_value` | 12 | 10 | 83.3% |
| `cashflow_op, enterprise_value, fnd6_newqv1300_cimiiq` | 17 | 8 | 47.1% |
| `operating_expense` | 33 | 16 | 48.5% |
| `cashflow_op, enterprise_value, fnd6_txtubxintis` | 8 | 0 | **0%** |
| `enterprise_value`（单独） | 6 | 0 | **0%** |

**读法**：`cashflow_op/enterprise_value` + `fnd6_xrent/assets` 这一对是历史命中率最高的组合形式；只要加进第三、第四个冷门锚，全过率能上 95%。

## 二、三条主力骨架（按强度排序）

### 骨架 A：三锚 + 双引擎 + 量能腿（最优，SF 5.9–6.19）

```
group_rank(fnd6_xrent/assets, subindustry)
+ group_rank(ts_av_diff(cash/assets, 45), subindustry)
+ group_rank(ts_av_diff(cashflow_op/enterprise_value, 45), subindustry)
+ group_rank(-ts_delta(close, 2), subindustry)
+ rank(volume/ts_mean(volume, 60))
```

## 三、骨架的组装规则（来自数据结构统计）

| 规则 | 实证 |
|---|---|
| **腿数 5–6 条** | A/B 档 5–6 腿占 61%；E 档 1–4 腿占 74% |
| **每条腿都套 `group_rank(·, subindustry)`** | 裸 rank 全过率 26.2% vs 分组 54.4%；换手差 3.1 倍 |
| **至少 1 条 PV 腿** | 砍掉 PV 腿 → testS 从 2.08 崩到 0.28–1.13，5 条挂 LOW_SUB_UNIVERSE_SHARPE（0914 batch113 + 0915 batch120 两次实证） |
| **锚腿用冷门字段** | 相关性墙是被"共享腿"顶破的；锚越冷门越好（`anl4_fs_detail_rec_v4_nd_estimate` alphaCount=24 是最冷门可用字段） |
| **不要给腿加 0.5 权重** | 全过率 67%→18.2%（除非专门为压相关性） |
