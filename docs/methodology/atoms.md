# atoms.md — 原子方法论库（唯一事实源）

> 建立：2026-09-28（李工拍板）。**本文件取代 00_总纲.md 成为方法论唯一事实源**；总纲降级为背景叙述（只读不再更新）。
> 原子 = 不可再拆的最小操作/事实。单条原子不构成完整配方，必须挂在骨架模板（T 类）上组合使用。
>
> **选择机制（不是轮询、不是随机，是三步决策）**：
> 1. **先查 D 类**：本次要做的操作在不在判死表里？死因类型适不适用本次语境？（有边界注明的，看语境是否落在边界内）
> 2. **再按"信息正交性"挑 M 类组合**：实证规律——给组合加一个池子里没有的信息维度（如 PEAD 盈余意外），远比在已有维度上做字段微扰有效（0927：正交融合 20 发入池 2 条，字段微扰 210 发 0 突围）。
> 3. **组合 = 骨架模板 T × 若干 M/C 原子**，生成批次发模拟；判墙后当场回写本文件（状态升级/降级/新增），不回写算违规。
>
> **墙的时效机制（李工 0928 问"判死是否有时效"的统一回答）**：
> self-corr 墙 = 候选 PnL 与已提交池每条 Alpha 的 PnL 相关性。池子只在**我们提交新 Alpha 时增加成员**；已交成员的 PnL 历史每天延长一天，corr 读数每天微漂（±0.01 量级）。所以：
> - **没有定时重置**。"等明天"唯一等来的是 corr 微漂，不是墙打开。
> - **我们自己每天交的 5 条就是改墙的工具**：交了 A 族 → A 族墙抬到天花板（同族候选 corr 0.85+），但池子拥挤度结构变化可能给 B 族让出豁免空间。
> - **正确姿势不是等，是每天低成本探**：留档候选每天用 judge_now 复判一遍（几分钟），微漂够了就复活。
> - **死因类型决定时效**（每条 D 类原子都标注）：权限类/数据类/语义类基本永死（改良方向见各条"能否改良"）；池状态类天然时变，可复活。

死因四类：
| 代号 | 含义 | 时效 | 改良方向 |
|---|---|---|---|
| PERM | 账号权限/平台功能限制 | 永死，直到账号升级（顾问面试通过可能解锁） | 等权限，无其他路 |
| MATH | 数学/截面语义事实（corr 由语义决定、质量结构约束） | 永死，但**适用边界**可能留活口 | 改变候选的语义内容（换正交信息维度），而不是在死过的方向上换参数 |
| DATA | 字段空数据/不存在 | 永死，除非平台加数据 | 换有数据的字段（先验证再设计腿） |
| POOL | 相对当前已提交池的状态 | **时变，可复活** | 每天低成本复判；主动用每日 5 条塑造墙形 |

## A. 骨架模板（T 类——原子的挂载点）

**T-01 三腿质量骨架（0927 主力）** `gr(质量/价值比) + gr(ts_av_diff(估值比,45~90)) + gr(-ts_rank(close,5))`
- 实例：LLN2e769（liab_curr/assets + cf/ev90 + 短反转，S2.55 F2.53 tS1.65）；qMxwl7a1 同模板换零引用 estimate 腿。
- 特性：自带质量引擎+短反转腿；**与池内 wpZJX6m5/e79kPeEM 家族共享全部三条腿语义**，破墙必须逐腿替换。

**T-02 五腿 anl4 综合骨架（9qj2qQPo 型）** 估值 + estimate 动量 + 分析师离散度 + 佐腿
- 特性：tS 好但 corr 0.72~0.73（守门员 kqVp6wnO/LLNXEe7L 网络）；换字段救不动（bt2 13 PASS 全灭），要动就动信息维度。

**T-03 日内几何低共享骨架（w200 型）** 日内反转主腿 + 2×独有锚(0.75) + 零标准 PV 腿
- 实例：3qXd5vg0 / zq8Xeo2R（09-18/19）。状态：POOL——参数区当时被占满，池漂移后可重探。

**T-04 PEAD 融合骨架（0927 bt3 型）** 质量/价值腿 + surprise 腿（actual−estimate）/|est| + 短反转
- 实例：wpZvrAoQ（S2.83 F2.62 tS2.94 豁免入池）。
- **已证边界**：去掉反转腿撑不起四闸（bt4 40 发 0 PASS，S 0.7~1.4）——PEAD 是佐腿不是主力。

## B. 有效原子（M 类，按破墙效力排）

**M-01 跨家族正交融合（0927 实证，当前最强）** 给骨架加一个已提交池没有的**信息维度**
- 实证：PEAD 腿（surprise = actual−estimate，anl4 配对字段大多零引用）首批 20 发出 2 条真豁免；同骨架字段微扰 210 发 0 突围。
- 可选正交维度（已入池缺失）：盈余意外（已用 ebitda）、分析师修正动量、目标价隐含收益、机构持仓变化。
- 操作：surprise 指标 × 配对字段在 `_autologs/_fields_usa.json` 按 actual/estimate 同指标配对查。

**M-02 零引用字段换非主导腿（0927 实证）** 第 2/佐腿换成 alphaCount<30 的字段（对手池没人用 → corr 天然低）
- 实证：bt1 模板 A 首批 3 条直通、qMxwl7a1 入池（cmax 0.6660）。
- 前提：① 字段有数据（先跑模拟验一条，防 D-22 假字段）；② 换的是佐腿不是主腿；③ 与被换腿语义正交（同语义换= D-06）。
- 边界：同模板赢家入池后，同模板家族全部判死（0.86+，bt1 尾部 37 PASS 全灭）。

**M-03 形态改造链（0927 李工"降换手提夏普"思路，3 条实证）** 筛形态达标的存量料 → 大 decay 压 TO → T1000 换池重掷 corr
- 筛选式：F≥1.2 / TO 0.29~0.61 / corr 0.78~0.82 / tS>2.8（Fcap=F×√(TO/0.125)，见 P-07）。
- 实证：j2AO3Xpe（de30→T1000，corr 0.6320 直通）、E5pxQlL9（de7→T1000，豁免过）。
- 关键判据：**源族 tS 必须高（>2.8）才有换池余量**；corr 0.85+ 或 O0N0R5NY/0mR2K6lr 网络成员直接跳过。

**M-04 中性化换挡 SUBINDUSTRY→MARKET/SECTOR** corr −0.09~−0.27/次
- 实证：O0N5o3Nv 0.7367→0.6467（0920）。前提：候选质量已达标。
- 边界：MARKET 伤 tS、SECTOR 保 tS；一个几何只能吃 1~2 口；**对同族扎堆无解**（0920 第 4、5 次判死 x214/x219）。

**M-05 换桶分组** `group_rank(x, subindustry)` → `group_rank(x, bucket(rank(慢变量), range="0.1,1,0.1"))`
- 慢变量：波动率桶 `ts_std_dev(returns,20)` / 成交额桶 `ts_mean(volume*close,20)`。
- 实证：88jKeENW 0.72+→0.6846（0920）。
- 边界：**对高同构家族无效**（0918 batch159 0/7 corr 0.84~0.996；0927 surg6z adv20 桶 0.876 再证）。

**M-06 低靶区 + 降 decay 顶 S 压豁免线** decay 10→6：S 2.45→2.55/2.58，压过 need
- 实证：0mXKpmYq（平台 corr 0.8042 照样放行）、KPNwG8Oj（0920）。
- 边界：**拐点立刻收手**（d4 起 TO 26%+、F 塌）；dec3 对高 TO 族直接爆闸（0927）。

**M-07 贴线 POST 试探** 本地 cmax 0.685~0.69 不判死，直接 POST（免费无副作用，被拒仍是 UNSUBMITTED）
- 实证：LLN2e769 本地 0.6860 → 平台 0.6851 ACCEPTED（0927）。
- 前提：本地/平台偏差双向 ±0.02~0.04（P-02），**只有 cmax≤0.72 才值得 POST**。

**M-08 兄弟 decay 差** 同族兄弟间降 decay 换 corr 读数
- 边界：**只在 corr 0.70~0.75 边界区有效**（0922 kqoQ2l2d 0.73→0.61）；对 corr ≥0.85 深重叠兄弟无效。每家 2 个探针值（de6/de3）足够判生死，别成批跑阶梯。

**M-09 高 S 主腿 + 独有锚**（0920 第一生产力，状态 POOL）
- 配方：`2.5*group_rank(-ts_rank(close/open-1,10), subindustry)` + 3×0.5 锚 + 0.4 引擎。
- ⚠ "追高 S 优于追低 corr"**已作废两次**（0920 豁免线 320+ 条全挡；0927 akbG6pM2 手术族再证 D-17）。此原子仅在直通路（corr≤0.685）有意义。

### MATH 语义/结构类（死因是数学事实；改良=换信息维度，不是换参数）

**D-06 同语义字段/锚微扰**（09-16 batch155 + 09-20 w218 两批 19 条）
- 为什么死：**corr 由截面语义相似决定，不是表达式共享**——w218 与 kqoq0zed 表达式零共享仍 corr 0.71+。换语义同类的锚/字段 = 同一个因子换马甲。
- ⚠ 边界（0927 修正，此条不是全域死）：换**信息正交**的新维度腿（M-01）或零引用字段（M-02）**有效**——qMxwl7a1 就是"换字段"但活了的实例。死的是"语义同类换"，活的是"信息维度换"。
- 改良：判断新字段与旧腿的语义距离——同类（都是估值/都是质量比）→ 死；正交（估值 vs 盈余意外 vs 修正动量）→ 用 M-01。

**D-07 腿稀释量产**（09-17 x174/175）单腿 ≈ −0.02 不可外推，赢家进池即成新撞点。改良：无——稀释不产生新信息。
**D-08 decay 拉大**（09-17 x176）12/12 corr 反升 +0.02~0.03——推向池子共同慢分量。改良：反方向（M-06 降 decay）。
**D-09 逐腿 group_rank→group_zscore / group_neutralize**（09-17 x178）14/14 质量摧毁。改良：无。
**D-10 顶层 zscore/rank 替换 group_rank**（09-16~17）丢中性化好处，质量/换手双崩。改良：无。
**D-11 结构级改造**（隔夜/日内拆分、条件符号切换、换手距离当主结构；09-14 batch104）solo SF 0.11~1.15。改良：换主腿语义。
**D-12 经典风格几何当主腿**（低波/长反转/波动率收缩/量能异动/流动性/中期动量；09-19 w209）8/8 standalone S −0.13~0.64，撑不起主腿。改良：降级为佐腿。
**D-13 隔夜/vwap 主腿**（09-19 w208）21000 组合 0 条 S≥2.0，矿脉不存在。改良：无（数据里没这个矿）。
**D-14 换分组救高同构家族**（09-18 0/7；0927 adv20 桶 0.876 再证）骨架同构 → 换什么分组都撞本体。改良：先去同构（M-01/M-02）再谈分组。
**D-15 事件腿加重/双腿/PV 减半当稀释**（09-20 w218_m）事件腿 0.5 是质量顶点，加重即塌。改良：无。
**D-16 pred 压过头**（≤0.58；09-19 w205）16 条 SF 1.4~2.1 质量崩。改良：回到 0.61~0.65 甜点区。
**D-17 增强信号=走向拥挤中心**（0927 akbG6pM2 手术族 14 发）把 S 推到 3.1~3.23 后全部撞进 pwRwWoJ3(3.33)/0mR2K6lr(3.45) 高 S 强墙 0.78~0.83——**候选变强 corr 反而升**，因为强信号大家都挖得到。改良：不追 S 高度，追信息独特性（M-01）。
**D-18 vec_avg 评级轴**（09-16 判、09-19 探针复验销案）SF ≤ 0.88。改良：无。
**D-19 强 trade_when 门控** 伤质量。改良：轻门控未见实证，低优先级。
**D-20 PEAD 单腿当主力**（0927 bt4 40 发 0 PASS）去掉反转腿后 S 0.7~1.4 撑不起四闸。改良：PEAD 只做佐腿（T-04）。
**D-21 同模板家族互撞（一池一家族一口）** 赢家入池即成头号撞点，同族第二批必死（09-13 起六次独立实证；0927 一天三证：bt1 尾部撞 qMxwl7a1 0.86+、surg4 撞 LLN2e769 0.87+、omLkdkGm 撞 wpZvrAoQ 0.98）。改良：**无**——这是 M-02/M-01 用完之后的必然代价，对策是入池前算好"这口吃完还剩哪些族"，而不是吃完再想。

### POOL 池状态类（时变，可复活——每天低成本复判）

**D-25 换池 TOP1000/TOP500**（0910~0914 判死 → **0927 复活** ⭐死→活标本）
- 当时为什么死：池子还小（~30 条），T1000 版 corr 结构与 T3000 相近，换了白换。
- 为什么活了：池子涨到 140 条后，T3000 与 T1000 的 corr 网络差异拉大；配合 M-03 形态改造（源族 tS>2.8 有余量）换池重掷有效（j2AO3Xpe corr 0.6320）。
- ⚠ 新边界：强族 T1000 版已被占满（MPakMndk 黑洞 corr 0.83~1.0，0927）——换池不是普适复活术，非强族才有效。
- 教训：**判死条目必须写死当时的池状态**，池状态变了必须复判。

**D-26 新数据轴单独成腿压不下 corr**（09-14~0915 判死 → **0927 部分复活** ⭐死→活标本）
- 当时为什么死：单腿 SF 1.1~3.4，加进旧组合后压不下 corr。
- 为什么活了：0927 发现真正的问题不是"新轴没用"，是"旧组合里新轴被旧语义稀释"——把新轴当**正交信息维度**重组骨架（T-04），PEAD 首批即破墙（wpZvrAoQ）。
- 教训：判死的是"旧配方+新腿"，不是"新轴"本身。

**D-27 家族参数区占满**（日内几何 P_int10/20 夹死，09-19 w206）——POOL 类典型：当时两条已入池夹死参数区；池漂移后空间可能重开。复判成本：一批 8 发。
**D-28 存量积压筛尽**（0916 456 条最低 corr 0.6934；0920 326 条达标候选直通 1 条）——当时的快照。留档候选（surg27 批 14 条 S3.1+、bt3 omLkdkGm S2.74 等）每天 judge_now 复判探微漂。

## E. 参数标定（P 类，数值带日期）

**P-01 pred→real 偏移三定律**（09-18/19）
1. 主腿权重占比 >0.5 偏移失控（+0.22）；≤0.4 可信（+0.04）。
2. 偏移与 pred 负相关（corr −0.69）：pred 越低偏移越大，压 pred 阈值方向是反的。
3. 跨几何锚偏移 +0.08~0.10。
- 旧常数标定"+0.12"已推翻（共享占比是主调制变量）。

**P-02 本地 corr ↔ 平台偏差** 双向 ±0.02~0.04（0920 A_MAR −0.0016；0927 1YX0LpAX −0.044、9qj2qPo +0.019）。缓冲线 0.685；cmax≤0.72 才值得 POST。

**P-03 平台判决规则** self-corr 硬阈值=0.7（0927 9qj2qPo 判决书原文 `(FAIL, 0.746, 0.7)`）；corr≥0.7 进豁免判定：候选 S ≥ 1.10×max(对手 S) 放行。对手集 `--corr-floor 0.66` 宁可多收（漏收=假豁免，j2Az8n0E 案例 0920）。

**P-04 TO 甜点** F=S×√(R/max(TO,0.125))——TO 10%~12.5% 最优，<12.5% 无额外收益。高换手批 S 高 0.5+ 但 F 反低 0.3+。

**P-05 窗口标定** ts_av_diff 窗口 45 生死攸关（SF 6.19 vs 30/60 的 1.33）；量能窗口 120>60>90；cf/ev 窗口 90 可用（0927）。

**P-06 结构甜点** 5~6 腿；裸 rank(x) SF2.38/T0.469 → group_rank(x,subindustry) SF5.89/T0.152。算子上限 64（约 5 腿）。

**P-07 Fcap 形态筛选公式** Fcap=F×√(TO/0.125)——形态改造料的筛选核心（M-03 配套）。
