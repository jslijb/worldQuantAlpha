# 面试代表作讲解卡（3 条真实提交的 Alpha）

> 来源：台账 `SUBMITTED_LEDGER.csv` 真实提交记录，指标为提交时实数。背熟**卡 1 为主力**，卡 2/3 备胎。
> 讲解顺序固定：先报指标 → 逐段讲表达式 → 收在经济逻辑。被追问再看"追问预案"。

## 卡 1（主力）：pwRwWoJ3 —— 现金流估值偏离 + 财务质量 + 反转，六腿复合

**指标**：Sharpe 3.33 / Fitness 3.58 / 换手 12.07% / 年化收益 14.45% / 回撤 3.05% / 自相关 0.65 / Decay 10 / 中性化 SUBINDUSTRY / 提交 2026-09-16

**表达式**：

```
1.5*group_rank(ts_av_diff(cashflow_op/enterprise_value, 45), subindustry)
+ group_rank(fn_accrued_liab_curr_a/assets, subindustry)
+ group_rank(-annual_intangible_assets_net_carrying_value/assets, subindustry)
+ group_rank(fnd6_xrent/assets, subindustry)
+ 1.5*group_rank(-ts_rank(returns, 20), subindustry)
+ 1.5*group_rank(-ts_mean(abs(returns)/volume, 20), subindustry)
```

**逐段人话**（6 条腿，前三条基本面、后三条量价）：

| 腿 | 表达式 | 人话 | 为什么有权重 1.5 |
|---|---|---|---|
| 1 | `ts_av_diff(cashflow_op/enterprise_value, 45)` | 经营现金流/企业价值 = "便宜且能赚钱"的估值比率；ts_av_diff = **今天相对近 45 天均值的偏离**——即估值比最近变好了多少 | 主力腿，贡献最大 |
| 2 | `fn_accrued_liab_curr_a/assets` | 流动应计负债/总资产 | 辅助 |
| 3 | `-annual_intangible.../assets` | **负号**：无形资产占比高做**空**——保守会计的公司更实在 | 辅助 |
| 4 | `fnd6_xrent/assets` | 经营租赁负债/资产 | 辅助 |
| 5 | `-ts_rank(returns, 20)` | 近 20 天涨幅时序排名取负——**跌多的做多**（短期反转） | 主力腿 |
| 6 | `-ts_mean(abs(returns)/volume, 20)` | 单位成交量噪声取负——**单位换手贡献收益低**（流动性差的票）做空 | 主力腿 |

**经济逻辑（收尾必讲）**：基本面三腿选"现金流扎实、会计保守"的好公司（质量因子），量价三腿做短期反转（跌多的弹回来）。两组信号相关性低、互补，所以合成后 Sharpe 比单腿高。group_rank 在子行业内排名——同行业里比，消除行业景气度的干扰，这就是中性化选 SUBINDUSTRY 的原因。

**30 秒口语稿**："这条是我跑出来指标最好的一条，Sharpe 3.33、Fitness 3.58、换手只有 12%。六条腿：三条基本面——核心是经营现金流对企业价值的比率，用 ts_av_diff 取它相对 45 天均值的偏离，也就是估值最近变便宜的幅度；再加应计负债、无形资产负向、租赁负债，都是质量类因子。三条量价——20 日反转、单位成交量噪声取负。全部在子行业内 group_rank 消除行业差异，加权合成后中性化用 SUBINDUSTRY。经济逻辑是质量加反转两组低相关信号互补。"

## 卡 2（备胎）：9qjqm3Q9 —— 现金占比改善 + 流动性质量 + 反转

**指标**：Sharpe 2.92 / Fitness 2.77 / 换手 11.87% / 收益 11.22% / 回撤 2.81% / 自相关 0.66 / Decay 10 / SUBINDUSTRY / 2026-09-16

**表达式**：

```
1.5*group_rank(ts_av_diff(cash/assets, 45), subindustry)
+ group_rank(ts_av_diff(assets_curr/assets, 30), subindustry)
+ group_rank(fn_accrued_liab_curr_a/assets, subindustry)
+ group_rank(-ts_delta(close, 20), subindustry)
+ group_rank(-ts_rank(returns, 20), subindustry)
+ group_rank(-ts_mean(abs(returns)/volume, 20), subindustry)
```

**逐段人话**：腿 1 = 现金/总资产的**45 天改善幅度**（公司在攒现金）；腿 2 = 流动资产占比的 30 天改善（资产结构变流动、变健康）；腿 3 = 应计负债（同卡 1）；腿 4-6 = 20 日价格反转 + 收益时序反转 + 单位量能噪声负向（与卡 1 同构）。

**经济逻辑**：**财务质量改善动量**——现金占比在提升、资产结构在变健康的公司，基本面在改善但市场反应慢，叠加短期反转腿抓超跌。和卡 1 的区别：卡 1 是"估值水平偏离"（便宜了没有），卡 2 是"质量改善"（在变好），两卡自相关 0.66，分属不同信号族。

**30 秒口语稿**："这条抓的是财务质量改善：现金占总资产的比、流动资产占比，各取近 30-45 天的改善幅度——公司基本面在变好的早期信号。叠三条量价反转腿。换手 11.9%、回撤 2.8%，防御性比较好。"

## 卡 3（备胎）：e79PvPpE —— 回购 + 保守会计 + 六腿同构

**指标**：Sharpe 3.13 / Fitness 2.72 / 换手 19.18% / 收益 14.52% / 回撤 3.37% / Decay 4 / SUBINDUSTRY / 2026-09-13

**表达式**：

```
group_rank(authorized_stock_buyback_amount/assets, subindustry)
+ group_rank(-annual_intangible_assets_net_carrying_value/assets, subindustry)
+ group_rank(ts_av_diff(cash/assets, 45), subindustry)
+ group_rank(ts_av_diff(cashflow_op/enterprise_value, 45), subindustry)
+ group_rank(-ts_delta(close, 10), subindustry)
+ rank(volume/ts_mean(volume, 120))
```

**逐段人话**：腿 1 = **回购金额/资产**（公司在掏真金白银买自己的股票——管理层认为股价低估的最硬信号）；腿 2 = 无形资产占比负向（保守会计）；腿 3/4 = 现金占比与现金流估值改善；腿 5 = 10 日价格反转；腿 6 = 当日量/120 日均量（放量关注，唯一一条全池 rank 腿）。

**经济逻辑**：**管理层行为信号**——回购是真金白银的表态，比利润表更难粉饰；配上保守会计与现金改善，全是"公司实打实在做什么"而不是"报表说什么"。

## 追问预案（每条都可能被问，答案统一背）

| 追问 | 答 |
|---|---|
| `ts_av_diff` 是什么 | 今天值减过去 d 天均值，"偏离度"算子——衡量当前值相对自己近期常态变了多少 |
| 为什么用 group_rank 不用 rank | 在子行业内排名，**消除行业间系统性差异**——现金流比率天然行业间不可比（银行和软件没法直接比），组内比才公平 |
| 为什么加负号（-无形资产、-ts_rank） | 无形资产占比高 = 报表"虚"的成分多，做空它；ts_rank 取负 = 跌多的做多，反转方向 |
| 中性化为什么选 SUBINDUSTRY | 子行业是最细分组，组内公司商业模式最接近，中性化掉的东西最干净；代价是组小、统计噪声大——试过 INDUSTRY，SUBINDUSTRY 综合最好 |
| Decay 为什么 10 / 4 | Decay 是对中性化后权重做线性衰减平均，降换手；10 在这两条上把换手压到 12% 左右、Fitness 最优，是调出来的拐点，不是越大越好 |
| 多条腿为什么用 + 直接加 | group_rank 输出已在 0~1 均匀分布、同量纲，可直接加权；系数 1.5 是给贡献大的腿加权，回测对比定下来的 |
| 自相关 0.65 会不会太高 | 提交门槛是 <0.7（或 Sharpe 高出 10%），0.65 过线；我后来的版本通过换池、换窗口把新条目的相关性往下压 |

## 研究流程介绍口径（诚实、且不露怯）

"我的工作流是：从财报结构和市场行为出发定**因子方向**——比如'现金流扎实+会计保守的公司长期跑赢'这类有经济逻辑的假设；然后批量构造表达式变体、并发跑回测，按 Sharpe/Fitness/换手/回撤硬门槛过滤；过线的做相关性检测，只留和已有池子互补的；最后提交。跑批和代码部分我用 AI 辅助实现，但**方向假设、门槛设定、每条因子的经济逻辑解释和去留决策是我做的**——像刚才这条六腿因子，每条腿为什么在、为什么这个权重，我都能讲。"

**红线**：不主动说"我没动手回测"——流水线是你设计的、门槛是你定的、这些 Alpha 就是你账号提交的真实产物，这不算编造；但**也绝不夸大成"全部手写代码"**，被追问编码细节就按上面口径答。
