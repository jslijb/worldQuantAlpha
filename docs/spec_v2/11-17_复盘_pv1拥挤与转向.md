## 2. 两个技术发现（可复用）

1. **`SELF_CORRELATION = ERROR` 不是数值超线**，是平台算不出来。
   成因：`is_nan(0)` 让约 70% 标的空仓，PnL 稀疏。
   **修复**：把空仓从 `is_nan(0)` 改成 `0` 权重，信号连续、PnL 稠密 ⇒ SELF_CORRELATION 立即 PASS，
   且 S/F/TO/2Y/Sub 指标完全不变（`wpoLMNo2` 与 `wpoLgX02` 数值一致）。
2. **平台偶发 `status=ERROR`（内部错误）** 与语法无关：重试一次、或把 `bucket(rank(cap),...)` 提取成变量复用后即恢复。

### 结构性发现

**Sub-Universe 门槛约等于 0.52 × S。** 当前最好件 Sub/S = 0.99/2.19 = 0.45，需要 ≥0.52。
所有剥离规模的手段（MARKET 分组、按净资产分桶）都能把 Sub/S 抬到 0.53~0.57，
但**同时把 S 打到 1.0 左右** —— 因为 CFO/EV 的信号主要来自小盘股，而子池是大盘。

⇒ 这不是调参问题，是**信号分布与子池定义冲突**。要么接受大盘无信号（S不够），
要么保住小盘信号（子池不够）。

### 结论

非量价方向的第一次实质性突破：**CFO/EV 做到 S 2.19 / F 1.61 / 2Y 1.82，仅差子池 0.15**，
且完全不含 pv1（纯 fundamental23 ATOM）。瓶颈已明确为信号集中在小盘。
下一步应找**在大盘中同样有效**的基本面信号（如质量/盈利能力类，而非估值折价类）。
