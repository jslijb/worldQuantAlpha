## 0a. 目标函数 = 官方评分算法（2026-09-20 归档原文，优先级高于所有反推模型）

> **⚠ 2026-09-26 口径更新（李工确认，优先级高于本节 0920 内容）**：本节的"Quantity/Quality 双因子、日上限 2000"是**顾问资格赛第一阶段**的积分体系（已通关，历史）；当前处于**面试阶段**，challenge 榜 isScore = **PERFORMANCE 合并池表现分**——动态重算、会掉、非逐条求和（实测 0925→0926 净 −177，ΣS/ΣF 对不上总数）。低 corr 互补候选的边际贡献 > 高 selfCorr 条。本节以下原文留档（"质量取平均、别堆边际条、Fitness 是最大杠杆、selfCorr 越低越好"这些方向性结论仍成立）。证据链 → `.workbuddy/memory/2026-09-26.md`。

来源：`docs/study/learn/docs/01_discover-brain/07_scoring-algorithm-challenge-users.md`
（平台 `GET /tutorial-pages/scoring-algorithm-challenge-users` 原文归档，非二手推断）

- **按天结算**："Score is tied to day, not to individual Alphas"。
- **两个因子**：Quantity（当天条数）+ Quality（当天所有 Alpha 质量因子的**平均**），两者在**当天所有提交用户间归一化**。
- **★ 每日上限 2000，原文明写 "Typically, this involves submitting 1 to 2 alphas a day."**
  ⇒ 单日堆数量在 1~2 条即饱和；且 Quality 取**平均**，当天多塞一条差的会**拉低整批**。
  ⇒ **边际 Alpha 是负资产**：拉低当天质量均值，且入池后抬高后续所有候选的 selfCorr。
- **Quality 的四个官方子项**：`Universe`（池越小越好）/ `SelfCorrelation`（**越低越好**）/ `Fitness`（越大越好）/ `Delay`（D1 优于 D0）。
- **⚠ turnover 不在官方清单里**，它经由 **Fitness** 进入（`F = S × √(|ret| / max(TO, 0.125))`）→ **TO < 12.5% 之后不再有额外收益**。目标区间 **10%~12.5%**；"TO≤20%"只是及格线，不是最优。
- **我们的三个得分漏点（0920 实测）**：
  | 子项 | 实测 | 结论 |
  |---|---|---|
  | Universe | **97.9% 产出是 TOP3000**（最大池） | 该项拿最低分，**降池从未当得分项测过** |
  | SelfCorrelation | 74 条有记录，**均值 0.694**；**25 条 ≥0.70**（最差 1YwKML56 **0.9687**） | 降 corr 本身就是加分项，与"过墙"同向 |
  | Fitness | **均值仅 1.860**（F≥3.0 仅 1 条；1.5~2.0 有 49 条；F<1.5 有 21 条） | 单点最大杠杆 |
  | Delay | delay=1 占 90.6% | ✓ 已达标 |

**打法据此调整**：① 不再为凑数提交边际 Alpha；② 单日 1~2 条高质量即可拿满 Quantity，剩余产能用于**试新轴**而非**发变体**；③ 新增两个方向——**降池（TOP3000→TOP1000/500）** 与 **selfCorr 目标 <0.4**（当前 0 条达到）。

### 1.5 ★ 豁免线结论更正（2026-09-20 22:00，推翻当晚早些时候的判断）

**被推翻的旧结论**（当晚 21:00 前后写进本文件与 CLAUDE.md）：
> "全库 326/347 条达标候选逐条判定：直通 1 条、**豁免 0 条**。豁免线要 1.1× 池内最高 S，凡与 pwRwWoJ3(3.33) / 0mR2K6lr(3.45) corr≥0.7 的候选都得 S≥3.7+，没有一条够 → **两条路都走不通，全域封死**。"

**错因**：当时只拿**基线 decay**（d10）的候选 S 去比 `need`，**漏掉"decay 可以调 S"这一层**。原结论只在"候选 S 固定"时成立。

**更正后的实测事实（4 例，全部当天跑出来的）**：

| 候选 | 基线 S | 调 decay 后 S | 本地 `need` | 平台 selfCorr | 结果 |
|---|---|---|---|---|---|
| `x162_w164_04_MAR` d10→**d6**（0mXKpmYq） | 2.45 | **2.55** | 2.54 | **0.8042** | ✅ ACCEPTED |
| `w189_01__g_bdv` d10→**d6**（KPNwG8Oj） | 2.45 | **2.58** | 2.55 | **0.7725** | ✅ ACCEPTED |
| `w41_b__d4`（78NKjWL1） | 2.44 | **3.19** | 3.212 | 0.8149 | ❌ 差 **0.022** |
| `w39_i__d4`（QPb5G6ZQ） | 2.49 | **3.20** | 3.212 | 0.7504 | ❌ 差 **0.012** |

**四条硬结论**：
1. **平台真实判据 = 豁免线，不是 corr 硬阈值**。corr **0.77~0.80 照样放行**；两条被拒的 corr 反而更低（0.7504 / 0.8149）。**决定成败的是 `S vs 1.1×max(对手 S)`，与 corr 高低无关**（只要 ≥0.7 进入该判定）。
2. **本地 `need` 算得准，4 例一分不差**。`--corr-floor 0.66`（宁可多收对手）的保守设定被验证为**正确**。
3. ⚠ **`need` 是时变的**：池子每入池一条，相关家族的 `need` 就抬一次。**必须用当前池实时算，禁止引用历史日志里的 need**（当天此坑踩到：`w39_i`/`w41_b` 的旧 need 写 2.71/2.46，实际已 3.212，误判为"够线"去打、被拒）。工具 `submit_exempt.py` 每次运行都重算，直接用它。
4. **本地 0.6862 → 平台 0.6846（偏移 −0.0016，平台比本地还低）** ⇒ 0.685 缓冲线偏保守，**0.685~0.69 这段不要判死，直接 POST 测**（免费无副作用）。

**⇒ 当前有效出量路径（按效力）**：① 换桶分组（直通，最干净）；② 低靶区 + 降 decay 顶 S 压线（豁免）；③ 中性化换挡 / 跨族混合（家族消耗型）。

### 3.2 本地 corr 判决参数
- **缓冲线 0.685**（09-16 标定）：pnl_corr 本地值 + 0.006~0.017 ≈ 平台值，误差 ±0.02 内。本地 ≤0.685 才可提交。

- leg_lab 预测 PnL vs 实测 PnL corr 仅 0.83~0.96（09-16）——线性近似有上限。
- **PnL 线性近似成立**（09-16）：PnL(Σwᵢ·腿ᵢ) ≈ Σwᵢ·PnL(腿ᵢ)；算 S 必须用原始日 PnL（扣均值则 S 恒 0）；G 与 Mmat 同尺度。

## 5. 提交判决机制（2026-09-16 定案）

- **判决 4~9 秒就出，不存在排队积压**。`POST /alphas/{id}/submit`（201）→ 轮询同端点：`200+Retry-After+空 body` = 计算中；**`403 + {"is":{"checks":[...]}}` = 判决书**；alpha 变 ACTIVE = 入池。
- **唯一拒信判据 = 出现 `FAIL`**。无 FAIL 的 403 回执（带 PASS 与数值）是"都过"的回执，不是拒信。超时只记 UNKNOWN，绝不记 REJECTED。
- **三种假判决**（全部是自家工具 bug，没有一次是平台的问题）：
  1. 旧 `blind_submit.py` 只认顶层 status/stage 键 → 判决书被当空数据丢弃（"假 PENDING"两天，0914~0915）；
  2. `SELF_CORRELATION=PENDING` 是未提交 alpha 的默认占位符，不是"正在算"（09-15）；
  3. 无 FAIL 的 403 回执被旧逻辑判成 REJECTED（09-16，QPbP6aRQ 实际已入池却被漏记）。
- **判决书 `is.selfCorrelated.records` 自带对手明细**（id/corr/sharpe）→ **提交即测量**，豁免线逐条算。`correlations/self` 端点弃用（09-16）。
- **必须串行提交**：并发 POST 201 会互堵、永不裁决（0914 实测 4 条）。
