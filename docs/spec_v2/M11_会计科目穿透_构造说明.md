# M11 会计科目穿透 — GLB 版构造说明

> 手工构造，不套形态模板。日期 2026-11-16。目标 idea：M11（`docs/methodology/idea.md:286`）。

---

## 1. idea 在赌什么

**机制原文**：绕开利润表、**直接计入权益**的会计科目，市场定价最不充分。

三个成立条件：
1. 不进利润表 ⇒ 分析师模型常不覆盖，卖方盈利预测里看不到；
2. 常为大额负值（养老金重算、外币折算差额）⇒ 容易被当成"一次性噪音"忽略；
3. 与资产负债表其他科目低相关 ⇒ 不是盈利能力、不是应计、不是杠杆。

**赌的是**：这块权益变动已经发生，但还没被价格反映。

与 M04 质量溢价的分界：M04 看利润质量（应计、毛利），M11 看**根本没经过利润表的那部分**。

## 2. 为什么是 GLB + fundamental23（不是 USA fundamental2）

这一步是硬约束筛出来的，不是偏好。

| 市场 | M11 科目所在数据集 | 能否用 | 原因 |
|---|---|---|---|
| USA | fundamental2 | **不能** | fundamental2 在 USA 已提交 355 条里已被使用（R10：USA 只用历史未用数据集） |
| USA | fundamental23 | 部分可用 | 该数据集未用，但里面只有 `accumulated_other_comprehensive_assets` 一个 OCI 字段，且 cov 仅 **0.623**（低于 M11 边界 cov≥0.7），且**没有** `assets_total_2` 做分母 → 配不出对 |
| EUR | 无 | 不能 | OCI / 租赁 / 股权激励 / 债务发行 关键词全覆盖为 0 |
| **GLB** | **fundamental23** | **可以** | OCI 字段 cov 0.705 ≥ 0.7；同数据集有 `assets_total_2` cov 0.960；未受 USA 数据集限制 |

GLB 的 fundamental23 是 1441 个 MATRIX 字段的大表，M11 需要的三类科目齐全：

- OCI：`accumulated_other_comprehensive_assets`（cov 0.705，**userCount = 0**）
- 表内融资负债：`finance_lease_debt_total`（cov 0.887，uc=3）
- 融资活动：`fnd23_debt_issuance`（cov 0.922）、`fixed_long_term_debt_repayment`（cov 0.847，uc=0）

## 3. 为什么选 `accumulated_other_comprehensive_assets`

候选只有它一个（GLB 全表 OCI 类字段搜出 0 条其他匹配）。

选它而不是租赁/债务发行的理由：

1. **它才是 M11 的"纯血"科目**。债务发行、租赁付款是"未来流出/契约义务"，属于 M11 表里 E1102~E1107 的边缘分支；OCI 是唯一"已经发生、直接进权益、不进利润表"的科目，正好命中机制三条件。
2. **cov 0.705 刚好过 M11 边界**（原文：只用 cov≥0.7，cov 0.6 那批信号钝，见 D-30 判死）。
3. **userCount = 0**：平台无人用过，不存在"被人挖烂"的相关性风险。
4. **可解释的符号方向**：OCI 高 = 净资产里有一块市场没看见的正收益 ⇒ 相对便宜 ⇒ 做多。方向单一，不需要试符号猜。

替代项为什么不选：
- `finance_lease_debt_total` cov 高，但它是**已确认的表内负债**，不是"绕过利润表"，机制不合；
- `fnd23_debt_issuance` 是融资节奏，属于 M11 表里 E1106，语义偏离核心（不是权益科目），留作配腿。

## 4. 为什么是这套算子（逐层解释）

```
group_scale( ts_delta( accumulated_other_comprehensive_assets, 252 ) / assets_total_2 , subindustry )
```

### 第 1 层：`ts_delta(..., 252)` —— 把"存量"还原成"当期流量"

GLB 只有**累计** OCI（accumulated，期末余额），没有 USA 那版"当期 OCI 净额"（other_comprehensive_income_net_tax）。

- 累计余额是历史沉淀，包含十年前的外币折算；它是**估值状态**，不是**新信息**。
- M11 赌的是"这块变动还没被定价" ⇒ 要的是**当期变动**。
- 252 个交易日 ≈ 一个交易年，差分即"过去一年的权益穿透流量"。

**这一步是 GLB 与 E1101 的唯一实质差异**，也是必须做差分的原因。不做差分，拿到的是存量比，跟"未定价的新信息"无关。

### 第 2 层：`/ assets_total_2` —— 规模标准化

OCI 是绝对金额。大公司的外币折算差额天然大于小公司，直接用金额排序等于在赌"市值大小"。

除以总资产后变成"每单位资产的权益穿透强度"，才可横截面比较。

用 `assets_total_2`（cov 0.96）而不是 `assets_total_3`（cov 0.937）：覆盖率更高且 userCount 更低。

### 第 3 层：`group_scale(..., subindustry)` —— 剔除行业性 OCI

OCI 的行业成分极强：
- 跨国零售/能源：外币折算差额随汇率整体波动；
- 银行/保险：AFS 证券重估；
- 养老金密集行业：折现率变动。

不剔除行业均值，因子会退化成"做多跨国企业 / 做空本土企业"。

用 `group_scale` 而不是 `group_rank`：
- `group_rank` 已按你的要求停用至 2026-11-23；
- `group_scale` 在 11-15 的 GLB 四条件上实测过线（S 2.50~2.85），是当前唯一有 GLB 过线记录的横截面算子。

选 `subindustry`：M11 原文配方就是 subindustry，且它是 OCI 行业差异最细的切分。

### 为什么没有加 ts_zscore / 时序标准化

台账实测（11-16 形态实验）：`group_scale(ts_av_diff(...)/ts_std_dev(...))` 与直接 `group_scale(ts_av_diff(...))` 相比，S 只会更低。时序标准化在这个 idea 上不提供增量，反而不必要地压缩了极端值——而 M11 赌的正是"大额、被忽略的极值"。

## 5. 与已验证件 E1101 的对应关系

| 项 | E1101（USA，已验证 SF3.72） | 本件（GLB） |
|---|---|---|
| 分子 | `other_comprehensive_income_net_tax`（当期流量） | `ts_delta(accumulated_other_comprehensive_assets, 252)`（存量差分还原流量） |
| 分母 | `assets` | `assets_total_2` |
| 横截面 | `group_rank(..., subindustry)` | `group_scale(..., subindustry)`（rank 停用） |
| 数据集 | fundamental2（USA 已用，不可复用） | fundamental23（GLB 可用） |
| 符号 | 正 | 正 |

**这不是换皮，是换币种口径**：USA 用当期净额，GLB 只有累计余额，所以必须差分。差分会引入两个风险：
1. 年度差分把季度级 OCI 事件抹平；
2. 累计余额的会计口径变更（如准则切换）会产生一次性跳变。

这两条是本件的主要证伪点，先跑一条正向、一条负向对照。

## 6. 对照实验设计

| 编号 | 表达式 | 目的 |
|---|---|---|
| P1 | `group_scale(ts_delta(accumulated_other_comprehensive_assets,252)/assets_total_2, subindustry)` | 主假设 |
| P2 | 同 P1 取负 | 符号证伪：若负向明显强于正向，说明 GLB 的 OCI 是"坏消息未定价"而非"好消息未定价" |

判读口径：
- P1 显著优于 P2 ⇒ 假设方向成立；
- 两者接近 0 ⇒ 年度差分把信号抹平，改试 126 天或改回存量水平；
- P2 明显优于 P1 ⇒ 符号反了，记录为 M11-GLB 符号差异。

## 7. 实测结果（2026-11-16，GLB TOP3000 / fundamental23）

| # | 表达式核心 | alpha_id | S | F | TO | 结论 |
|---|---|---|---|---|---|---|
| P1 | group_scale(ts_delta(acc_oci,252)/assets_total_2, subindustry) | 1YWavPjR | **0.08** | 0.01 | 0.037 | 无信号 |
| P2 | 同 P1 取负 | 58JaNXJ1 | **−0.08** | −0.01 | 0.037 | 完美镜像 ⇒ 非符号问题 |
| P3 | ts_delta(acc_oci,126)/assets_total_2 | pwaVQNm6 | 0.01 | 0.00 | 0.067 | 更差 |
| P4 | ts_mean(acc_oci/assets_total_2,60) | KPgXYn21 | −0.06 | −0.01 | 0.017 | 存量水平无效 |
| P5 | ts_rank(acc_oci/assets_total_2,500) | rK7J627d | **0.28** | 0.06 | 0.029 | 本组最好，仍差 1.30 |

分区 S（P5）：AMER 0.30 / EMEA 0.10 / APAC 0.07，全部低于 1.0。

### 诊断

1. **TO 0.017~0.037**：因子几乎不动（累计 OCI 一年才更新一次）⇒ 属于"静态标签"，与未来收益无关时表现为 S≈0 且 TO 极低。这是慢变存量因子的典型形态。
2. **差分没有救回来**：252 天与 126 天差分都接近 0，说明"年度变化"这个口径没有信息量。
3. **根因是概念错位，不是信号弱**：USA 版 E1101 用的是**当期 OCI 流量净额**（`other_comprehensive_income_net_tax`），GLB 只有**累计余额**。累计余额主要由外币折算差额（汇率漂移）构成，与"管理层没有报告的权益变动"不是同一信息。
4. **cov 0.705**：30% 标的无值，横截面稀疏，进一步稀释。

### 结论边界（不得外推）

这条结论只能表述为：**GLB 的 fundamental23 累计 OCI 字段无效**。
**不能**表述为"M11 会计科目穿透 idea 无效"——USA 版 E1101 有实测 SF3.72 的验证记录，两者口径不同源。

### 下一步（按优先级）

1. 换 M11 内其他科目（同数据集 fundamental23，语义仍对齐"绕过利润表"）：
   - `finance_lease_debt_total / assets_total_2`（表内融资租赁负债强度，uc=3）
   - `fnd23_debt_issuance / assets_total_2`（再融资节奏，uc=82）
2. 若坚持 OCI，必须在有"当期 OCI 净额"字段的数据集上做，而 USA 该类字段全在 fundamental2（已用）⇒ 需换市场口径或等解禁。
3. 慢变基本面因子优先用 `ts_rank(x, 500)` 形态，不用差分（P5 优于 P1/P3）。

## 8. 按 idea 原式微调（2026-11-16 17:00，group_rank 解禁后）

### 8.1 硬事实：M11 原始字段在 GLB 全部缺失

`other_comprehensive_income_net_tax` / `current_minimum_operating_lease_payment` /
`future_minimum_operating_lease_payments` / `sbp_equity_nonvested_count` /
`fn_entity_common_stock_shares_out_a` / `option_award_outstanding_count` /
`debt_issuance_proceeds_2` / `debt_repayments_total` / `line_of_credit_repayments` / `assets`
—— **在 GLB 字段表里逐一查，全部 MISSING**。GLB 根本没有 `fundamental2` 数据集（GLB 共 69 个数据集）。

因此 M11 只有三个分支能在 GLB 找到同数据集等价字段（fundamental23）：

| idea 原式 | GLB 等价字段 | cov |
|---|---|---|
| E1106 `debt_issuance_proceeds_2/assets` | `fnd23_debt_issuance / assets_total_2` | 0.922 / 0.960 |
| E1107 `-(debt_repayments_total+line_of_credit_repayments)/assets` | `-fixed_long_term_debt_repayment / assets_total_2` | 0.847 / 0.960 |
| E1102 `current_minimum_operating_lease_payment/assets` | `finance_lease_debt_total / assets_total_2`（语义弱化：表内而非表外） | 0.887 / 0.960 |

E1101（OCI）/ E1104（股权激励稀释）/ E1105（期权稀释）在 GLB **配不出单数据集对**：
OCI 在 fundamental23、股本在 fundamental23、期权在 fundamental72 —— 跨数据集即混血，不发。

### 8.2 替换算子对照（subindustry 分组 + MARKET 平台中性化 + decay20）

| 分支 | 表达式 | alpha_id | S | F | TO |
|---|---|---|---|---|---|
| E1106 | `group_scale(fnd23_debt_issuance/assets_total_2, subindustry)` | d5aEnKQw | −0.21 | −0.04 | 0.024 |
| E1106 | `group_rank(...)`（原式算子） | MP6Kxo38 | **−0.06** | −0.01 | 0.020 |
| E1107 | `group_scale(-fixed_long_term_debt_repayment/assets_total_2, subindustry)` | ZYa2ja1Z | **0.32** | 0.09 | 0.017 |
| E1107 | `group_rank(...)`（原式算子） | mLarX3ax | 0.02 | 0.00 | 0.017 |

结论：
- **E1107 上 `group_scale` 显著优于 `group_rank`（0.32 vs 0.02）** ⇒ “能换更好”成立，替换方向保留。
- E1106 上 `group_rank` 略优（−0.06 vs −0.21），但两者都远离门槛，差异无实质意义。
- 两个分支的分区 S 都低于 1.0（E1107：AMER 0.70 / EMEA −0.50 / APAC 0.05）。

### 8.3 当前结论边界

**能够确证的**：GLB 上用 fundamental23 的债务类等价字段实现 M11，S 天花板约 0.32。
**不能确证的**：M11 本身无效 —— 原式在 USA（fundamental2）有 SF 2.54~3.72 的实测记录，两处字段口径完全不同。

### 8.4 需要拍板的硬冲突

M11 的 OCI 主腿（E1101，已验证 SF3.72）**只在 USA 的 fundamental2 里**，
而 fundamental2 已被历史 355 条 USA 提交用过 ⇒ 与 R10（USA 只用未用数据集）直接冲突。

三条路：
1. **USA 对 fundamental2 开例外**（只针对 M11 这类已在文档里验证过的 idea）→ 最可能直接过门；
2. **坚持 R10** → M11 在 GLB 只能到 0.32 天花板，该 idea 暂时搁置；
3. **换未用数据集做语义变体**（如 `ai_equity_alpha` 的应计/修正族）→ 但那已经不是 M11。
