## 3. 参数标定（数值全部带日期）

### 3.1 pred→real 偏移三条定律（2026-09-18/19 标定，取代旧常数标定）
1. **主腿权重占比定律（09-19）**：主腿权重/总权重 **>0.5 时偏移失控**（w206：pred 0.59 → real 0.81，+0.22）；**≤0.4 时可信**（w200_05 占比 0.4，偏移 +0.04）。低权装饰腿的"去相关贡献"是幻觉——group_rank 截面结构会压制低权腿。
2. **偏移与 pred 负相关（09-18）**：15 观测 mean +0.29，corr(偏移, pred) = -0.69 → pred 越低偏移越大，**单纯压 pred 阈值方向是反的**；pred 0.49~0.55 区间 real 呈负斜率。
3. **跨几何锚偏移（09-19）**：+0.08~+0.10，约为 subindustry 锚（+0.05）的两倍。
- 旧标定 ~~"+0.05~+0.19，均值 +0.12"~~（09-16）：当时在"共享主导"regime 下测得，**已推翻 09-18**。共享腿占比是主调制变量：shared=0.14 → +0.07~+0.11；shared=0 → -0.03~+0.05（09-18/19）。

### 3.2 本地 corr 判决参数
- **缓冲线 0.685**（09-16 标定）：pnl_corr 本地值 + 0.006~0.017 ≈ 平台值，误差 ±0.02 内。本地 ≤0.685 才可提交。
- leg_lab 生成器阈值 `--max-corr 0.55~0.57`，产出后**必须 pnl_corr 复核**（09-16 定；09-18 起 awareness：偏移随共享占比调制，低共享区 pred 可信、可加 pred≤0.66 硬过滤）。
- leg_lab 预测 PnL vs 实测 PnL corr 仅 0.83~0.96（09-16）——线性近似有上限。
- **PnL 线性近似成立**（09-16）：PnL(Σwᵢ·腿ᵢ) ≈ Σwᵢ·PnL(腿ᵢ)；算 S 必须用原始日 PnL（扣均值则 S 恒 0）；G 与 Mmat 同尺度。
- **pnl 数据是累计值，必须先差分**（09-16）；不差分任意两条 corr≈0.99。
- **池子只能取自台账**（0916 教训：pnl/ 缓存混入未提交候选 → corr 虚高压死一切）。

## 5. 提交判决机制（2026-09-16 定案）

- **判决 4~9 秒就出，不存在排队积压**。`POST /alphas/{id}/submit`（201）→ 轮询同端点：`200+Retry-After+空 body` = 计算中；**`403 + {"is":{"checks":[...]}}` = 判决书**；alpha 变 ACTIVE = 入池。
- **唯一拒信判据 = 出现 `FAIL`**。无 FAIL 的 403 回执（带 PASS 与数值）是"都过"的回执，不是拒信。超时只记 UNKNOWN，绝不记 REJECTED。
- **三种假判决**（全部是自家工具 bug，没有一次是平台的问题）：
  1. 旧 `blind_submit.py` 只认顶层 status/stage 键 → 判决书被当空数据丢弃（"假 PENDING"两天，0914~0915）；
  2. `SELF_CORRELATION=PENDING` 是未提交 alpha 的默认占位符，不是"正在算"（09-15）；

## 7. 研报移植方法论（0914~0915 沉淀）

- **只移植结构，不照搬数值**：论文自家 S+F 往往只有 1.86~2.69（Research16, JF 2022）。
- 两条表达式铁律：① `ts_mean` 对离散字段降换手无效，先连续化（rank/zscore/vec_avg）；② `? : NaN` 是 CONCENTRATED_WEIGHT 头号成因，改 `if_else(cond, ·, 0)`。降换手：`trade_when` 第三参用 -1；`hump(x,0.01)` 优于 ts_mean。
- CHN 无权限（0914 实测）；评级字段全在 analyst4 且全 VECTOR 必须 vec_avg（但评级轴本身已判死，§2#8）。
- 元教训（球队硬币帖，0914）：优秀量价因子 PnL 殊途同归 → 破局 = 叠加其他数据 + 不同数理方法处理同一数据。**日内几何主腿（09-18 破墙）正是这条教训的兑现。**
