## 一、先稳住：面试官怎么问"字段"

不会让你翻译英文字段名。高频就三类：
1. **字段有哪几种类型？**（必问：Matrix(截面数据) / Vector(向量数据) / Group(分组标签)）
2. **你怎么选、怎么评估一个字段？**（看：覆盖率 / 拥挤度 / 新鲜度）
3. **某类数据代表什么经济含义？**（fundamental(基本面) / 价量 / analyst(分析师) / alternative(另类数据)）

你已有的实战底子（直接拿来当答案）：
- 提交过 36 条 **Amihud(非流动性) 流动性** Alpha → 你说"我用 volume(成交量) 类字段做过流动性因子"
- 主力用 **fundamental(基本面)** 字段（cashflow_op(经营现金流) / enterprise_value(企业价值) / fnd6_xrent(基本面字段-租金类)，其中 fnd6_ 是 fundamental6(基本面数据集6) 前缀）→ 你说"我用公司基本面字段做过价值因子"
- 踩过相关性墙 → 你说"我理解数据拥挤的概念，会主动避开被大量 Alpha 使用的字段"

## 二、字段三大类型（必背，几乎必问）

| 类型 | 含义 | 例子 | 关键约束 |
|---|---|---|---|
| **Matrix(截面数据)** | 每天全市场每只股票一个值 | price(价格) volume(成交量) returns(日收益) close(收盘价) | 直接进表达式 |
| **Vector(向量数据)** | 同一天、同一只股票有**多个值**（当天发生多个事件，如一天几条新闻、几个情绪打分） | analyst4_(分析师预期数据集前缀) 评级/预期逐期修订；新闻 nws12_*(新闻数据集前缀) 情绪 scl15_*(情绪数据集前缀) | 必须 vec_avg(求平均) / vec_count(计数) / vec_sum(求和) 压成 Matrix(截面数据：每天一个值) 才能用 |
| **Group(分组标签)** | 只做分组键，不算数 | sector(行业大类) industry(行业中类) subindustry(行业小类) market(市场) | 只用于 group_rank(分组内排名) / group_neutralize(按组分摊) 的分组参数 |

**面试加分点（踩坑经验）**：Vector(向量数据) 字段不转就裸进表达式 = 把"一天多个事件值"当"截面值(每天一个值)"用，结果必然错；必须用 vec_*(时序转截面) 算子把一天多个值压成每天一个值。

⚠️ **面试易错点（修正）**：cashflow_op(经营现金流) / enterprise_value(企业价值) / fnd6_*(基本面数据集6) 这些 fundamental(基本面) 字段在 BQ 上是 Matrix(截面数据)，直接进表达式、不用 vec_*(时序转截面)，你的 36 条 Alpha 就是这么跑的。vec_*(时序转截面) 真正要用的只有 analyst4_*(分析师预期数据集前缀) 这类分析师预期的历史序列。

**面试加分点（怎么区分字段和算子）**：只看**英文函数名后面跟的圆括号 `( )`**——**自己带 `( )` 的 = 算子（函数形态），裸写不带括号的 = 字段或分组标签**。中文翻译用的全角括号 `（）` 不算数，别被它带偏。
- 例：`group_rank( pasteurize( sales_growth ), sector )` 里，`group_rank` 和 `pasteurize` 自己带圆括号 = 算子；`sales_growth(销售增长 基本面营收增长率)`、`sector(行业大类)` 裸写 = 字段（`sector` 是 Group 分组标签）。
- ⚠️ **纠偏（易错）**：不是"括号里是字段、括号外是算子"。括号**里面**装的是"参数"，参数既可以是字段（`sales_growth`），也可以是**另一个算子**——`pasteurize(sales_growth)` 整个就嵌在 `group_rank` 的括号里当第一参数，而它自己也是算子。真正判断只看"这个词自己带不带圆括号"。

**参数位置规律（第二个参数一般是什么）**：
- 分组类算子 `group_rank(数值, 标签)` / `group_neutralize(数值, 标签)`：第二参**必是 Group 标签字段**（sector 行业大类 / industry 行业中类 / subindustry 行业小类 / market 市场）。
- 时序类算子 `ts_rank(x, 20)` / `ts_mean(x, 20)`：第二参是**数字**（时间窗口长度，如 20 天）。
- 单层算子 `rank(x)` / `pasteurize(x)`：只有 1 个参数，没有第二参。
- 所以"第二参是标签"只对 group_*(分组类) 算子成立，不是所有算子都这样。

这表达式 `group_rank( pasteurize( sales_growth ), sector ) - group_rank( sales_growth, sector )` 的用意：把销售增长平滑去噪后在行业内排名，减去未平滑的原始排名，捕捉"去噪后信号相对原始信号的增量"（去噪增强手法）。

## 二补、Delay(延迟) 到底是什么（全局设置，不是字段属性）

- **delay(延迟) 是回测设置里的一个参数，作用在整个 Alpha(阿尔法) 的"决策→建仓"时机上，不是某个字段的属性。**
- 官方定义：delay(延迟) = 数据相对决策时间的可用性（你决定买某只股票后，假设多久能真正成交建仓）。
- **delay=0(延迟0)**：今天收盘前看到数据 → 今天就用今天的数据建仓（激进）。
- **delay=1(延迟1)**：今天决定 → 明天才成交，用的是今天的数据（保守，留 1 天滞后，防前视偏差(用未来信息)）。平台默认 delay=1(延迟1)，表达式里自动处理，不用手写。
- 对 Matrix(截面数据) 字段的直观效果：delay=1(延迟1) = 用"前一个交易日"的值（比如 close(收盘价) 字段 Delay 1 = 昨天的收盘价）。你这个直觉对，但根因是"全局滞后 1 天"，不是字段自己带 delay。
- 对 Vector(向量数据) 字段：delay(延迟) 同样是全局滞后。你之前理解的"开盘到收盘波动都保留"是错的——vector(向量) 是事件型数据（新闻/情绪），一天多条，不是分时价格；delay(延迟) 只是把滞后天数加在已经 vec_*(时序转截面) 压好的"每天一个值"上。

**一句话**：delay(延迟) 管的是"信号滞后几天能成交"，matrix(矩阵) 和 vector(向量) 都受它管；它不决定字段里存几个值。

**那 Data Explorer(数据浏览器) 顶部为什么有 Delay(延迟) 筛选？**（官方原话：Some data fields are present only in certain regions and delays——有些字段只在特定地区和延迟下才存在）
- 字段表达式里确实不写 delay(延迟)，但**字段底下的数据是不是"当天就能拿到"是数据源本身的属性**：价量数据当天收盘就有 → 有 delay=0(延迟0) 版本；财报类数据要等发布、新闻要等录入 → 只有 delay=1(延迟1) 版本。
- 所以顶部 Delay(延迟) 下拉框的作用 = **筛出"在这个延迟下有数据"的字段**。切到 delay=0(延迟0) 列表会变少（基本只剩价量类），delay=1(延迟1) 才是全量。
- 实操规则：**你回测 Settings(设置) 里选的 delay(延迟)，必须和字段存在的延迟一致**——在 delay=0(延迟0) 回测里用只有 delay=1(延迟1) 的字段，会报错或没数据。

## 三、数据家族与经济含义（被问"这字段啥意思"就这么答）

| 家族 | 经济含义 | 典型字段 | 你用过？ |

## 四、怎么选 / 评估一个字段（讲这套，就是 6 tips 浓缩）

1. **股票覆盖率（Instrument Coverage(股票覆盖率)）要高**：这个字段里，有多少比例的股票是有数值的。比例越高越好——比如 90% 的股票都有数，比只有 40% 的好。低于 70% 就要小心，因为一大半股票没数据，信号是残缺的。
2. **日期覆盖率（Date Coverage(日期覆盖率)）要满**：这个字段是不是每个交易日都有更新。满=每天都更新，好；不满=有些日子是空的。
3. **少人用（低拥挤）**：用过这个字段的 Alpha(已用该字段的Alpha数) 越少越好。用的人少=撞车（相关性高）的概率低，是金矿。
4. **新鲜度**：更新频率越高越好（日频 > 季度）。
5. **经济逻辑成立**：这个字段确实能量出你想验证的那个想法。
6. **避开"看着有、其实空"的字段**：有些字段在列表里存在，但绝大多数股票/日期都是空值。平台不会报错，但算出来全是空=白做。

一句话：**覆盖率高、少人用、意思对。**

## 五、被点名问某字段，现成话术（挑你会用的讲）

- `cashflow_op(经营现金流)`（经营活动现金流）→ 企业主业真金白银进账，比净利润难造假；常做 `cashflow_op(经营现金流) / enterprise_value(企业价值)` 现金流收益率（价值因子）
- `enterprise_value(企业价值)`（企业价值 = 市值 + 总负债 − 现金）→ 估值分母，越大说明整家公司越"贵"
- `cashflow_op(经营现金流) / enterprise_value(企业价值)` → 现金流收益率，价值因子：比值越高 = 越被低估
- `fnd6_xrent(基本面字段-租金类)` → fundamental6(基本面数据集6) 里的字段（具体经济含义以 Data Explorer(数据浏览器) 描述为准，租金/租赁类基本面信号），你的强腿之一，常和上面两个拼成"价值 + 质量"组合
- `returns(日收益)` → 日涨跌，做动量 / 反转
- `volume(成交量)` → 流动性
- `abs(绝对值)(returns(日收益)) / volume(成交量)`（Amihud(非流动性) 非流动性）→ 你 36 条全用它，价跌量小=非流动性高
