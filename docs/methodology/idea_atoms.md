# Idea 原子库（李工 2026-10-07 指令：idea 原子化 + 系统性两两/三三/四四组合）

> 目的：idea 不再当"一个方向一次性试完"，而是拆成原子登记，组合由生成器枚举，判死状态逐格回写。
> 与 atom_factory（表达式原子）的区别：atom_factory 拆的是**已跑过的表达式**；本库登记的是**还没跑过的想法**（论坛帖/论文/自创），是组合的原料入口。

## 原子四类

| 类 | 含义 | 例子（今天实例） |
|---|---|---|
| D 数据原子 | 字段/字段族 | news_pct_120min（事件价格反应）、cpd90（call−put IV 差） |
| T 变换原子 | 单腿算子结构 | ts_arg_min 事件定位、ts_delta 动量、group_rank 比率、ts_regression 残差 |
| S 结构原子 | 多腿组合方式 | 线性加权、主腿+小剂量辅腿、比值形态（v5）、事件门控 trade_when |
| P 参数原子 | 池/中性化/decay/分组 | T1000 换池、MARKET 中性化、de60、industry 分组 |

## 状态标记

- `未测` → `探针死(S<1.5)` / `组死(过不了四闸)` / `墙死(corr 卡)` / `毒化(同族已入池)` / `入池` / `待测`
- **判死必须带量化证据**（最好 SF / corr 读数），与 docs/methodology/atoms.md D-表联动。

## 组合生成规则（待李工批）

1. **主腿 + 配平腿模板**：强 D×T 原子做主腿（权重 1.2~1.5），互补性质原子做配平腿（0.3~0.8）。互补 = 一个补 tS、一个补 corr、一个补 TO，不许三个同质。
2. **枚举受控**：每批 ≤8 发，主腿家族 ≤2 个（防同族互毒），配平腿从不同 D 来源抽。
3. **判死联动**：D-表已判死的 (D,T,S,P) 四元组不再生成；"毒化"数据集只允许做 ≤0.4 剂量配平腿。
4. **缺口优先**：从未测过的 (D,T) 格子优先于已试格子的变体。
